# 击感实验室 · 生成作品索引

本目录保存「击感实验室」每个模型独立制作的横版战斗试玩。
可直接用浏览器打开下表的 `project/game.html`（或 `index.html`）试玩；
或者在仓库根目录运行 `StartCombatBench.bat` / `python writing-bench/combat_bench.py --serve`，访问 <http://127.0.0.1:8805/>。

评分来自 Opus 5.5 对最终可玩版本的匿名评审：命中反馈 / 动作衔接 / 攻防节奏 / 肢体破坏，满分 100。

> 仓库保留了可玩项目、评测 JSON 和关键试玩截图（`sample-*.png`）；
> 模型 transcript（`events-*.jsonl`）、Chrome 缓存、依赖与逐帧录屏已排除。
