# 断傀夜行 · Dismantle the Puppets

横版动作战斗试玩：月下废都中的刀客对阵机械傀兵。单文件离线可玩，无外部资源，图形全部 Canvas 程序化绘制，音效全部 WebAudio 实时合成。

## 玩法

**核心循环**：`J` 三段连斩积攒敌人的**气绝值**（敌人头顶黄条）→ 打空后敌人跪地**气绝硬直** → 此时 `K` 蓄力重斩**斩断肢体**；满蓄力重斩不依赖气绝也能断肢。断肢直接改变敌人行为：

- **断臂**：失去对应攻击手段；**双臂尽断**的傀兵会进入自爆倒计时——远离或抢先击杀。
- **断腿**：移动速度大减（一腿 45%，双腿 22%）。
- **断头**：索敌与瞄准错乱，攻击方向随机出错。
- 敌人死亡时残肢碎裂飞散。

**敌人**（三种主动行为，均有可见前兆）：
- **刃傀**：快速近身，红光蓄力后突刺。
- **锤傀**：重甲（轻击弹开减伤），高举重锤震地——起跳或闪避躲开冲击波。
- **铳傀**：保持距离激光瞄准射击；飞行弹可以被挥刀**弹反**。

**手感**：命中顿帧按攻击力度分级（轻斩 50ms → 满蓄力 150ms），顿帧后时间平滑恢复；配合冲击式震屏、刀光拖尾、命中火花、击飞/挑空/下砸、残影冲刺与连击计数。

## 按键

| 键 | 作用 |
|---|---|
| A / D 或 ←→ | 移动 |
| Space | 跳跃（二段跳） |
| J | 三段连斩（命中后可连段） |
| K | 按住蓄力重斩（松开出招，满蓄可断肢）；空中为下砸 |
| L | 无敌帧闪避（可取消出招/蓄力） |
| I | 地面挑空；空中下砸 |
| R / Enter | 重开 / 开始 |
| M | 静音 |

## 运行与构建

- 直接双击打开 `game.html` 即可（离线、无网络依赖）。
- 源码在 `src/`，`node build.mjs` 将各模块拼接为单文件 `game.html`。
- `window.combatBenchState()` 返回 `{ready, playerAlive, enemyCount, hitCount, limbBreakCount, playing}`。
