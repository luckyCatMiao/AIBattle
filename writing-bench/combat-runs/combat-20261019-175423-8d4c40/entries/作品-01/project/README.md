# 绯月 · 断刃 — 横版斩击试炼

一个离线可玩的单文件横版动作战斗 demo。直接用桌面浏览器打开 `game.html` 即可，无需服务器、网络或外部资源。

## 玩法

| 键位 | 动作 |
| --- | --- |
| A / D 或 ← / → | 移动 |
| Space | 跳跃 |
| J | 轻斩四段连击，第四段把敌人挑空 |
| K 按住蓄力 / 松开 | 重斩，蓄力越久越重，专破敌方肢体 |
| L | 瞬步闪避（带无敌帧） |
| I | 弹反（精准架开近战与红玉弹） |
| R | 一键重开 |
| Enter | 开始 / 死亡后重开 |
| 1 | **月轮斩**：原地旋身，360° 绯色刀轮横扫周身，弹开红玉 |
| 2 | **影袭·断踪**：瞬身突进并在路径敌人身上留下斩痕，随后连锁引爆 |
| 3 | **刃雨**：跃起召来六柄灵刃依次钉落，范围伤害与硬直 |
| 4 | **绯月·千刃一闪**：终式，短暂迟滞战场后五轮斩光连锁爆发，最后一记横贯全场的月牙巨斩 |

系统设计：

- **四段轻斩**逐段提速推进，命中后可缓冲接续（缓冲在顿帧期间也保留）；**第四段挑空**后跳起用空中 J 追打，或空中 K 下劈（plunge）制造落地范围冲击。
- **重斩**按住 K 蓄力三段，蓄力时有可见蓄势姿态、逐步增强的火花与光环；重击对肢体造成 2.2 倍伤害，是主要断肢手段，同时可破铁面武士的正面格挡。
- **弹反**有 0.24s 窗口与 0.62s 冷却，成功时触发强顿帧、震屏、击退与 1.4s 破防；可弹反弹回的招式包括近战与红玉弹。
- **分段肢体**：头（要害）/ 左右爪臂 / 下肢，各自独立血量与判定。断爪后该敌人失去攻击手段、只会绕行逃窜；断腿则移动迟缓，悬浮的红玉傀儡会直接坠落；断头即死。断肢会作为实体飞出、弹跳并留在地面。
- **三种敌人**：碎骨鬼（快速三段爪击，末段跃击）、铁面武士（正面格挡、长前摇重劈与突进）、红玉傀儡（悬浮投掷追踪红玉；红玉可被 J 斩或弹反反弹成高伤弹幕；施法时会俯冲到触手可及的高度，形成地面反击窗口）。
- **命中反馈**：按轻/重/断肢分档的顿帧（约 0.04–0.18s），配合有上限的短促震屏、刀光弧线、火花、伤害数字与敌人受击动作，不使用满屏闪白。
- **四个主动技能**：1-4 键触发，各有独立冷却（4.5 / 6.5 / 8.5 / 20 秒），左下角技能条实时显示可用状态与倒计时；技能词条见 `skill_manifest.json`。
- **波次循环**：清场后约 1.1s 进入下一波，敌人持续补充；死亡后 R 或 Enter 立即重开。

## 项目结构

- `src/` — 可读源码（util / audio / fx / player / enemy / world / render / hud / main / style）
- `build.js` — 将源码与样式内联打包成 `game.html`
- `test/` — 无头验证脚本（DOM/Canvas 桩 + jsdom 端到端）
- `tools/` — 渲染快照与性能测量脚本（开发辅助，非交付依赖）

## 构建与自测

```bash
node build.js
node test/harness.js        # 主战斗回归：命中、断肢、重开、状态接口
node test/invariants.js     # 64 秒高压连续游玩，检查数值/实体不失控
node test/dom_e2e.js        # jsdom 真实 DOM 端到端（Enter 开局、静音按钮、面板）
node test/buffer.js         # 顿帧期间的攻击输入缓冲
node test/aircombo.js       # 挑空、空中追打、下劈
node test/orbfire.js        # 傀儡发射与反弹红玉
node test/audio_mock.js     # 16 种合成音效在 mock AudioContext 下不抛错
node test/html_load.js      # 交付 HTML 结构 / 无外部依赖 / 无身份泄露
node test/limb_effect.js    # 断爪后停手、断腿迟缓坠落、断要害即死
node test/highwave.js       # 高波次持续刷新不卡死
node test/puppet_ground.js  # 只在地面也能打到悬浮傀儡（俯冲窗口）
node test/helpless_kill.js  # 断臂敌人会守住原地、可被普通攻击终结
node test/coldstart.js      # 冷启动到首次命中的时间测量
node test/skills.js         # 四个技能：触发、伤害、冷却、时间迟滞、断肢
node test/dom_skills.js     # jsdom 中真实按下 1-4 键触发四技能
node test/skill_soak.js     # 技能混入常规战斗的 60 秒稳定性压测
```

`game.html` 不依赖网络、CDN 或外部资源；图形全部 Canvas 绘制，音效全部 WebAudio 合成。首次点击或按键启用音频，右下角提供静音按钮；无音频环境不影响游戏运行。

`window.combatBenchState()` 返回真实状态：`ready`、`playerAlive`、`enemyCount`、`hitCount`、`limbBreakCount`、`playing`。

## 自测结果（本轮）

- 19 个验证脚本全部通过：主战斗回归、64 秒高压连续游玩（含技能混战）、jsdom 真实 DOM 端到端、顿帧输入缓冲、挑空追击、傀儡发射/反弹、音效空跑、HTML 结构、断肢后果、高波次刷新、地面反击窗口、断臂终结、冷启动计时、四技能触发/冷却/断肢、DOM 按键触发技能。
- 冷启动实测：首个敌人 0.53s 出现，1.70s 首次命中。
- 性能实测（1600x900 软件光栅）：绘制约 4ms/帧，逻辑约 0.014ms/步。
- 构建可复现：连续两次 `node build.js` 产物哈希一致（`2fc5e90d…`）。
- 交付文件无网络引用、无 localStorage/父窗口/下载/弹窗依赖，无调试钩子；`window.combatBenchState()` 只读且返回真实状态。
