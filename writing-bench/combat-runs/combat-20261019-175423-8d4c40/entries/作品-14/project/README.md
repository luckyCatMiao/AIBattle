# 断界：霓虹处刑场

`game.html` 是可离线直接打开的完整单文件横版动作战斗试玩，无网络、字体、图片或音频依赖。画面由 Canvas 即时绘制，声音由 Web Audio 合成。

## 操作

- `A / D` 或 `← / →`：移动
- `Space`：跳跃
- `J`：三段斩；再次按键可预输入下一段
- `K`：按住蓄力，松开重斩；满蓄力可直接破坏普通敌人武装
- `L`：无敌影冲，可取消部分攻击收招
- `I`：瞬反；在敌人红光攻击即将命中前使用，成功后自动接反击斩
- `1`：裂帛·瞬光——无敌贯穿斩
- `2`：星坠·断层——跃升后坠地范围击飞
- `3`：磁狱·缚轮——持续牵引、悬浮与伤害场
- `4`：终式·千隙葬——多目标瞬移连斩与同步断肢终爆
- `R`：随时重新开始
- `Enter`：开始；死亡后重新开始

三段斩的第二、第三段会累积武装破坏，终结技可以切断普通敌人的武器肢体。收割者失去刀臂后改为冲撞，射手失去炮臂后改为近身头槌。

## 文件

- `game.html`：最终游戏，也是未经压缩的完整源码
- `test-runtime.js`：Node 下的 DOM/Canvas 环境桩与确定性战斗测试，不是游戏运行依赖
- `skill_manifest.json`：四项新增技能的试玩清单
- `TASK.md`：原始任务说明

## 自测

运行：

```sh
node /workspace/test-runtime.js
```

测试覆盖启动、统一按键、四项技能的独立触发/资源/冷却/真实命中与场域效果、真实三连命中、终结技断肢、两类敌人断肢后的行为变化、近战瞬反、持续刷新、敌人击杀玩家、Enter/R 重启、静音降级，以及 6900 帧以上混合输入压力流程。

游戏按要求暴露不可改写的 `window.combatBenchState()`，返回被冻结的真实战斗状态对象。
