# 斩骸夜行 · 木偶讨伐试炼

横版动作战斗系统试玩。月夜下讨伐失控的武傀儡——刀客、弓手、重锤傀儡均有**分段肢体（头/双臂/双腿）**，重斩与连段会把肢体打断飞散，断肢改变其战法（缴械、跛行、狂乱）。

最终交付物为 **`game.html`**（单文件，离线可直接双击运行，无任何外部依赖）。

## 操作

| 按键 | 动作 |
| --- | --- |
| A/D 或 ←/→ | 移动 |
| Space | 跳跃（可二段跳，站高台按 S/↓ 下落） |
| J | 三段连斩（可接挑空/影步/跳跃取消） |
| K | 重斩；**按住蓄力**，满蓄「满月斩」必断肢 |
| I | 升龙挑空 → 跳起接空中三连斩 |
| 空中 K | 坠斩砸地（带落地冲击） |
| L | 影步（无敌帧）；**擦过攻击瞬间触发「看破」慢镜**并返还冷却 |
| **U** | **奥义·弹反·镜花**：架势中被打中→化解并自动拔刀追斩（含拨回弓箭），必定断肢 |
| **O** | **奥义·瞬影·一閃**：墨影穿行，齐斩沿途所有敌人（多目标慢镜） |
| **H** | **奥义·樱吹雪**：消耗 40 剑气，回旋三段范围攻击，全程无敌帧并挑空 |
| **Y** | **奥义·落月·断罪**：引月跃起坠落，大范围重击+击飞+必断肢（长冷却大招） |
| R | 立即重开 |
| Enter | 开始 / 再战 |
| P | 暂停 |
| 鼠标 | 仅用于开始与右上角静音按钮 |

四个奥义均为独立按键、带冷却（游戏内左下角有技能冷却栏实时显示，标题页附完整招式表）。连段收招中可直接取消接续奥义。

剑气槽命中充能，满槽下一击化为「破军」（伤害翻倍、必定断肢）。每波肃清回复少量生命。

## 手感设计要点

- **命中顿帧分级**：轻击 ~45ms、重击 90–150ms、断肢/终结更长；顿帧期间输入进缓冲队列，恢复后连招无缝衔接。
- **克制的震屏**：创伤平方模型 + 快速衰减 + 方向偏置，仅命中时施加；重击附带轻微变焦冲击。
- **可读的攻防**：所有敌人攻击有姿态前摇 + 眼睛变红 + 武器凝光 + 危险弧线提示，前摇后半段锁定朝向（可绕后）。
- **肢体破坏**：断肢为实体碎片，带物理弹跳、能砸伤其他敌人；断持械臂=缴械转冲撞，断腿=减速，断头=狂乱易伤。
- **慢镜节点**：看破闪避、终结清波、死亡，配蓝色晕影。

## 项目结构

```
src/
  00_core.js     工具/全局状态/输入(缓冲+失焦清键)/WebAudio 音效合成/粒子
  01_world.js    夜幕背景(视差远山/月/石灯笼)/花瓣/地面高台/断肢实体/弩箭/冲击波
  02_player.js   剑客状态机：连段/蓄力/挑空/空中连击/坠斩/影步/骨骼IK姿态/刀光拖尾
  03_enemies.js  三种敌人 AI、分段肢体与破坏结算、木偶绘制
  04_game.js     命中结算/波次管理/HUD/标题与死亡流程/主循环/window.combatBenchState
build.js         将 src/ 依序打包为 game.html
test/harness.js  Node VM 桩环境自动化自测（模拟游玩120s+）
test/visual.js   node-canvas 真实渲染 + 像素探针断言 + 截图(test/shots/)
game.html        构建产物（可离线直接游玩）
```

## 构建与自测

```bash
node build.js        # 生成 game.html
node test/harness.js # 自动化玩法自测（无需浏览器，模拟游玩 ~200s）
node test/visual.js  # node-canvas 真实渲染 + 像素探针断言 + 截图(test/shots/)
node test/soak.js    # 300 秒浸泡测试（死亡自动重开，验证无长时异常）
```

## 对外状态接口

`window.combatBenchState()` 返回真实运行数据：
`{ ready, playerAlive, enemyCount, hitCount, limbBreakCount, playing }`

另有只读调试接口 `window.combatDebugState()`（内部坐标/AI 状态，供自动化测试使用，不影响玩法）。

## 运行环境说明

- 纯 Canvas 2D 绘制、WebAudio 合成音效，无网络/CDN/外部资源、无 localStorage。
- 自适应窗口：窄窗保证 ≥1000px 视野宽，宽屏自动扩展；游戏按键已阻止页面滚动，失焦自动暂停并清空按键。
