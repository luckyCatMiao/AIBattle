# 断缘傀儡 · KIRI DOLLS — 横版动作战斗试玩

一个离线可玩的单文件横版动作战斗试玩。全部图形用 Canvas 2D 程序化绘制，全部音效由 WebAudio 实时合成，无任何外部资源。

**交付物：`/workspace/game.html`** （单文件，直接双击在桌面浏览器打开即可游玩）

---

## 玩法

在被遗忘的神社废墟中，你是最后一名「断缘」剑客，面对被丝线操控的傀儡群。

| 按键 | 动作 |
|------|------|
| `A` / `D`（或 ←/→） | 移动 |
| `Space` | 跳跃（空中可再跳一次） |
| `J` | 斩击（四段连段，最后一段挑空） |
| `K` | 蓄力重击（按住蓄力，满蓄力为「断」） |
| `L` | 冲刺闪避（带无敌帧，可取消攻击后摇） |
| `I` | 地面：弹反 / 空中：坠击 |
| `S` + `J` | 低扫（专打腿部关节） |
| `R` | 重新开始 |
| `Enter` | 开始 / 确认 |
| `Esc` | 暂停 |

鼠标只用于：点击开始按钮、静音按钮。

### 核心战斗循环

- **连段**：`J` 四段 → 末段挑空 → 跳起空中三连 (`J J J`) 追击 → 落地继续。连段窗口宽松，可在出招中预输入。
- **弹反**：`I` 有 0.19 秒主动帧，成功后敌人硬直、镜头轻震、短暂无敌，并额外增加连击数。主动帧有收缩光环提示，收招有红色缺口提示。
- **断肢**：敌人有 `头 / 前臂 / 后臂 / 前腿 / 后腿` 五个独立部位。剑刃实际扫过的部位才吃肢体伤害——
  - 断腿 → 身体下沉、行动迟缓；双腿全断 → 倒地拖行，只能爬过来
  - 断双臂 → 无法挥砍，只能用头撞
  - 断头 → 立即死亡
  断肢有独立的肢体飞散物（带丝线、会弹跳、会拖出血迹），断裂时有额外顿帧与音效。
- **命中有力**：命中顿帧（轻击 ~45ms、重击 ~85ms、满蓄力 ~170ms）、镜头震动（带噪声而非正弦抖动）、方向性火花、白光核心、屏幕边缘轻闪。

### 敌人（三种行为）

| 敌人 | 特征 |
|------|------|
| **裂刃 CUTTER** | 快速接近；单砍 / 二连斩 / 突进斩；会走位 |
| **重甲 COLOSSUS** | 高血量、霸体、缓慢推进；举刀蓄力后砸地（地面冲击波） |
| **鸣弦 CHORUS** | 保持距离，投掷旋转环刃（可弹反）；近身会后撤 |

所有敌人攻击前都有：红色/青色升腾光环 + 头顶警号 + 明显蓄力姿态。

### 适合反复试玩

- 波次制，清空后 1.5 秒即下一波，每波恢复少量生命
- 敌人持续刷新，难度随波次递增（第 3 波起出现重甲与鸣弦）
- 死亡后按 `Enter` / `R` 一键重开，2 秒内回到战斗
- 首次进入即可攻击（开始后有 1.4 秒的「第 1 波」横幅，但玩家可自由行动）

## 技术实现

```
src/
  index.html      — 页面骨架 + DOM 标题层 + CSS
  assets/         — 子集化并 base64 内联的中文字体（Noto Serif SC / Noto Sans SC）
  js/
    util.js       — 数学、插值、IK、线段距离
    input.js      — 键盘状态、输入缓冲、失焦清键
    audio.js      — WebAudio 合成音效 + 环境音乐
    particles.js  — 粒子、刀光带、伤害数字、地面贴花
    player.js     — 玩家状态机、关键帧姿态、程序化骨架与绘制
    enemy.js      — 三种敌人 AI、分段肢体、断肢飞散物、投射物
    game.js       — 战斗判定、顿帧、相机、波次、HUD、场景绘制
    hud.js        — DOM 开始界面
    main.js       — 启动、主循环、静音按钮、combatBenchState
scripts/
  build.js        — 把 src 全部内联成单文件 game.html（含字体 base64）
```

构建：`node scripts/build.js` → 输出 `/workspace/game.html`

### 关键手感设计

1. **顿帧只在命中时触发**：攻击起手与挥空完全没有停滞。权重分级（轻/重/断肢/击毁），且用 `hitstop` + `freeze` 双层，恢复平滑。
2. **震屏用 Perlin 噪声**而非正弦，trauma²衰减，避免机械感。重击时配合极轻微的 zoom punch。
3. **刀光带**是真实扫掠几何：每帧记录剑根/剑尖，用锥形四边形连接，边缘高光 + 白色前缘。
4. **敌人受击反应**包含：受击方向倾斜、部位局部闪白、硬直打断、击退与浮空。
5. **浮空追击**有轻微空中吸附，让连段不断，但不接管控制权。
6. **肢体伤害只由剑刃真实接触决定**（线段-线段相交），所以站着乱砍会打 torso，蹲下扫腿才能断腿。

### 自测

使用 Playwright + Chromium 无头环境做了以下自动化验证（`docs/` 内有截图）：

- 页面零 console / pageerror
- `combatBenchState()` 返回 6 个字段且类型正确，每次调用返回新对象（只读语义）
- 连段：四段 `l1→l2→l3→l4` 依次触发并循环
- 顿帧：命中瞬间 `hitstop` 从 0 → 0.045，3 帧后平滑归零
- 冲刺取消攻击后摇，位移 ~113px
- 弹反：主动帧内挡下敌人攻击，玩家血量不变、敌人进入 stagger
- 断肢：低扫一记即可断掉腿部关节；断头立即击杀；断肢计数正确
- 浮空：重击挑空 ~88px，空中追击成功衔接
- 死亡 → `state: 'over'` → `Enter` 重开 → 完整重置
- 音频：WebAudio 节点正常创建；静音按钮把 master gain 从 0.9 → 0 → 0.9
- 响应式：960×540 / 1920×1080 / 2560×1080 / 700×900 均正常，自动缩放镜头
- 失焦自动清空按键

### 已知取舍

- 美术使用程序化矢量骨架 + 分层绘制，不是手绘逐帧，因此动作风格偏「骨骼动画」，但每个招式都有可读的蓄力-出招-收招三段。
- 无尽波次，没有通关结局。
