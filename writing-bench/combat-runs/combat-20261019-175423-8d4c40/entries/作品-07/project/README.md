# 影刃 · 机关残响 — 横版动作战斗试玩

一个可直接离线游玩的单人横版动作战斗 Demo：玩家扮演持刀武者「影刃」，与不断刷新的
机关傀儡作战。核心是**有力度差别的命中顿帧 + 可断肢的敌人**：轻重连段、蓄力重斩、
挑空浮空、空连与坠斩构成一套可反复试玩的战斗系统。

## 运行

直接双击打开 `/workspace/game.html`（无需网络、无需服务器、无任何外部资源）。
游戏会自适应窗口，最小 960×540，宽屏同样适配。

- **Enter**：开始 / 确认
- **A / D 或 ← / →**：移动
- **Space**：跳跃（可变高度）
- **J**：轻斩 · 三段连击（地面）/ 空连斩（空中）
- **K**：重斩（地面，长按蓄力）/ 坠斩（空中）
- **L**：冲刺 / 闪避（无敌帧，可取消出招）
- **I**：挑空斩（把敌人打浮空）
- **U**：一闪·居合（疾冲贯穿，斩断沿途之敌）
- **O**：影舞·分身斩（召唤三道残影向前绞杀）
- **P**：雷葬·天罚（召雷轰击至多三名敌人）
- **Q**：残响·时滞（冲击波击退并迟滞周围敌人）
- **R**：重新开始
- 鼠标：仅用于「开始 / 再来一局 / 静音」按钮

## 玩法要点

- **剑傀儡**：近战，出招前有明显的红色预警光 + 抬剑前摇，可闪避。
- **炮傀儡**：远程，保持距离发射能量弹，有蓄能前摇。
- **肢体破坏**：敌人由头、双臂（剑 / 炮）、双腿等独立部件构成。重斩、第三段连斩、
  挑空、坠斩等强力招式会打断肢体——断攻击臂会失去出招能力，断腿会减速甚至无法移动，
  断头会陷入眩晕。
- **命中顿帧**：只有命中才冻结画面，轻重攻击顿帧时长不同；配合有节制的震屏、刀光、
  火花、伤害数字与击退/浮空/落地反馈。
- **连续试玩**：敌人持续刷新，死亡后 R / Enter 一键重开。

## 项目结构

```
/workspace
├── game.html          # 最终交付（由 build.js 打包生成的单文件）
├── skill_manifest.json# 4 个技能的操作清单（便于试玩）
├── build.js           # 构建脚本：src/*.js + style.css -> game.html
├── src/
│   ├── config.js      # 常量与招式/敌人数值
│   ├── util.js        # 数学工具
│   ├── audio.js       # Web Audio 合成音效
│   ├── input.js       # 键盘输入（防滚动、失焦清键）
│   ├── effects.js     # 粒子系统 + 顿帧/震屏/缩放冲击
│   ├── entities.js    # 玩家 / 敌人（分段肢体）/ 炮弹
│   ├── render.js      # Canvas 绘制
│   ├── game.js        # 主循环、战斗判定、刷怪、摄像机、状态
│   ├── main.js        # 启动、覆盖层、静音、音频解锁
│   └── style.css
└── test/
    ├── smoke.js       # 冒烟测试（开始/刷怪/命中/断肢/死亡重开/状态）
    ├── combat.js      # 战斗专项测试（挑空/空连/坠斩/炮击/受击/顿帧/无敌帧）
    └── skills.js      # 4 个主动技能专项测试（一闪/分身/落雷/时滞/冷却）
```

## 构建与自测

```bash
node build.js          # 重新打包 game.html
node test/smoke.js     # 无头冒烟测试
node test/combat.js    # 战斗系统专项测试
```
