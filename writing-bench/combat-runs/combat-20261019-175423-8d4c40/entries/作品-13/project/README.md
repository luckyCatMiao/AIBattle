# 断械 · 雨夜铸庭

一个可离线直接打开的横版动作战斗场景。最终文件：`game.html`。

## 开始与按键

用桌面浏览器打开 `game.html`，点击「进入铸庭」或按 Enter。不需要服务器、安装依赖或网络。

| 按键 | 操作 |
|---|---|
| A / D 或 ← / → | 移动；下一刀会采用新的输入方向 |
| Space | 跳跃，可二段跳 |
| J | 三连斩，可按住连续攻击；空中为追击斩 |
| K | 松开出重斩；按住约 0.46 秒完成蓄力，0.95 秒自动释放；空中为落断 |
| L | 无敌闪步，取消攻击/受击硬直，双充能自动恢复 |
| I | 升龙挑空，接 J 追击，再 K 落断；冷却 1.25 秒 |
| R | 随时重开 |
| Enter | 开始、死亡后重开、失焦暂停后继续 |
| 音效按钮 | 静音/恢复合成音效 |

所有游戏键阻止页面滚动。失焦或切换标签页会清空按键并暂停；Enter 或点击场景恢复。

## 四项独立技能（本轮新增）

数字键 **1 / 2 / 3 / 4** 独立触发，也支持小键盘；不替换原来的 J/K/L/I。开始面板和常驻技能栏均显示名称、按键、用途，技能栏显示各自冷却。

| 键 | 技能 | 战斗效果 | 冷却 |
|---|---|---|---|
| 1 | 掠雨一线 | 短蓄势后无敌贯穿约 330 距离，沿途 52 伤害、78 肢体损伤；切碎弹丸 | 3 秒 |
| 2 | 回澜锁月 | 环绕三拍 13 + 13 + 34 伤害；前两拍聚敌，第三拍挑空；前段短暂无敌 | 5 秒 |
| 3 | 双弧归燕 | 飞出约 430 距离再追踪归手，去程 26、回程 34 伤害；两程分别结算命中，回程削肢更强 | 4 秒 |
| 4 | 天钉落庭 | 锁定面前敌人当时的位置，阵纹先聚敌造成 16 伤害，延迟巨刃重落造成 76 伤害与强力断腿、击飞 | 7 秒 |

四招都可空中发动、接入原有战斗与闪步取消；飞刃和落钉释放后独立存在，玩家可继续移动攻击。冷却从按键成功施放开始，无蓝量或解锁门槛。命中依然通过原有真实伤害、受击与断肢链路；落钉砸空只有地面声效和特效，不制造命中顿帧。`skill_manifest.json` 包含恰好四项试玩操作清单。

新增源码：`src/skills.js`；新增测试：`node tests/skills.mjs`。测试仅向内存副本增加只读观察，不改战斗数值。`tests/skill-results.json` 记录逐招实际命中、断肢、往返独立判定、空中施放、冷却、闪步取消、重开及未修改交付文件在离线沙箱中的运行结果。技能重落击飞不足已在测试后增强；测试也等待命中顿帧结束后才检查缓冲的取消输入。

## 战斗设计

- 轻斩三段有独立准备、有效和收招阶段，支持提前输入和收招取消。攻击按真实距离/方向/高度检测，每刀每名敌人最多命中一次。
- 命中顿帧：轻斩 43 / 52ms，三段终结 78ms，重斩 100ms，蓄力重斩 135ms。断肢至少 105ms；挥空不顿帧。顿帧期间冻结战斗模拟，仍收集操作输入。
- 升龙将玩家与敌人带入空中；空中追击短暂托住目标，落断把敌人砸回地面。空中追击辅助有次数上限，不能无限飞行。
- 闪步两次充能，每次约 0.82 秒恢复；擦身躲过有效攻击会返还一次充能。闪步可以取消出招，是攻防转换而非单纯跑路。
- 敌人有分段骨架。重击和连续攻击累计真实的肢体损伤。断臂后武器模型脱离、旋转飞散并落地，敌人改为短距离弱近战；射手不再发射。断腿后腿段脱离、身体下沉，移动降至 30%，突进速度降至 105。断肢对象可以仍然存活，并非死亡粒子代替。
- 三类敌人：近战刀卫接近后蓄势突击；炮卫保持距离并用瞄准线预警射击；第二波起重装守卫以长前摇、大范围重击施压。红色警示和地面范围提示攻击方向。
- 连击计数、分数、血量、闪步充能和升龙冷却常驻显示。断械回复 3 生命，击破回复 2，清波回复 12；清波约 1.4 秒进入下一波。
- 程序生成的雨夜建筑、灯笼、角色姿态、围巾、刀弧、机械残肢、冲击碎屑和层次化音效。没有外部图片或声音文件，也没有全屏闪白。

## 文件与构建

- `src/game.js`：输入、战斗、敌人 AI、骨架绘制、特效、HUD、Web Audio 合成。
- `src/shell.html`：页面、开始/死亡面板、响应式布局。
- `src/ui-zh.woff2`：离线中文 UI 字体子集，避免没有中文字体的系统显示方框。
- `src/FONT-LICENSE.txt`：Noto Sans CJK SC 字体的 SIL OFL 许可；构建时也嵌入 HTML 源码。
- `build.mjs`：将上述内容打包为单文件。执行 `node build.mjs` 即可重建，无需 npm 安装。
- `subset-font.py`：可选的字体重建脚本。现成子集已保留，普通构建不需要 Python。
- `tests/smoke.mjs`：真实浏览器首次加载和按键实战。
- `tests/combat.mjs`：完整回归；仅测试内存副本增加只读观察点，不给交付文件增加测试后门，也不调整敌人或玩家数值。
- `tests/results.json`、`tests/*.png`：回归结果与截图。

运行测试需要 Playwright 和 Chromium：`node tests/combat.mjs`。当前容器缺少 NSPR/NSS/ALSA，`tests/browser.mjs` 会从隔离的 `test-tools/downloads/` 目录加载测试用共享库。这些目录与 npm 包不属于游戏运行依赖。

## 自测结果

在 Chromium 中通过：

1. 开始、横向移动、二段跳、空挥不顿帧。
2. 真实轻斩命中时双方位置/攻击时间冻结；蓄力重斩实测 135ms 顿帧。
3. 连斩断肢、存活敌人的武器臂断裂、独立残肢物理对象。
4. 挑空和空中追击、闪步位移/无敌/充能恢复。
5. 失焦清键、暂停和恢复，Web Audio 解锁为 running，静音切换。
6. 不操作时敌人主动进攻并击杀玩家，R 重开恢复血量并清零真实计数。
7. 普通按键自动实战进入第 3 波，确认重装敌人进入持续刷新循环。
8. 未修改的最终 HTML 在 `sandbox="allow-scripts"`、无同源权限的 iframe 中可以开始并真实命中敌人，外部网络请求数为 0。
9. 960×540 和 1920×800 的显示检查。
10. 浏览器运行时错误为 0。

声音合成节点和运行状态经过自动化检查；无头测试不等同于人工试听。

## 只读检测接口

`window.combatBenchState()` 返回实时快照：

```js
{ ready, playerAlive, enemyCount, hitCount, limbBreakCount, playing }
```

函数不可覆写；返回的是新对象，不是可修改的游戏状态引用。`playing` 在失焦暂停或死亡时为 false。无 localStorage、父窗口操作、下载、弹窗、网络、强制全屏或鼠标锁定依赖。
