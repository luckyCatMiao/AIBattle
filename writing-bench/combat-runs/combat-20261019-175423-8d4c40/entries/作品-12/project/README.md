# 断星 // RIFT REAVER

离线单文件横版动作战斗试玩。

## 运行

直接用桌面浏览器打开 `/workspace/game.html`。游戏不需要网络、服务器或外部资源。

## 操作

- `A/D` 或 `←/→`：移动
- `Space`：跳跃
- `J`：主攻击（三段连斩；空中为空斩）
- `K`：副攻击（地面按住蓄力；空中坠斩）
- `L`：无敌冲刺/空中冲刺
- `I`：精准弹反
- `1`：瞬狱・六连星（锁敌高速连闪）
- `2`：引力・葬月轮（聚怪多段挑空）
- `3`：裂界・赤雷贯（蓄势贯穿破武装）
- `4`：终式・天坠残光（全场落斩与坠星终结）
- `R`：重新开始
- `Enter`：开始

## 战斗设计

- 三段轻击中后两段分别提供位移与击飞，可在收招阶段继续输入。
- 重击有两级蓄力；高蓄力和轻击终结式会重点破坏敌人手臂。
- 空中轻击、空中冲刺和坠斩支持挑空追击。
- 弹反窗口位于起手后短时间内，成功后自动发动高破坏力反斩。
- 刃偶断臂后失去长武器，改用更慢、更短的撞击；炮偶断臂后失去射击能力，转为近战。
- 头部被破坏后，炮偶瞄准偏差与攻击间隔增大。
- 每次攻击具有独立命中顿帧、震动、音效、击退与受击姿态。

## 构建

源文件位于 `src/`。重新构建单文件：

```sh
node /workspace/tools/build.js
```

```sh
node /workspace/tools/test-manifest.js

```
