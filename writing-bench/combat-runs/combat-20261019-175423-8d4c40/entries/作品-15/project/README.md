# 锈潮 · RUST REQUIEM

一个完整、可离线直接打开的横版动作战斗场景。最终交付文件为 **`/workspace/game.html`**。不需要安装依赖、不需要启动服务器；桌面浏览器双击打开，按 Enter 即可进入战斗。绘图使用 Canvas 2D，声音使用 Web Audio 合成；字体以内嵌 WOFF2 提供。

## 操作

| 按键 | 动作 |
|---|---|
| A / D、左右箭头 | 移动 |
| Space | 跳跃；空中可再跳一次 |
| J | 三段连斩，可按住连续出招 |
| K | 地面点按重击，按住约 0.48 秒蓄满后松开断械；空中使用落刃下劈 |
| L | 无敌闪身，可取消攻击或蓄力；冷却 0.48 秒 |
| I | 磁升挑空，消耗 30 磁核；自身随攻击升空，可衔接空中 J / K |
| Q | **缚星磁涡**：环形聚敌、打断，冷却 4.8 秒 |
| E | **裂轨一闪**：无敌穿阵，切口延迟爆裂断臂，冷却 3.8 秒 |
| U | **双月回轮**：双向往返月刃，出手后可自由行动，冷却 5.5 秒 |
| O | **天炉裁决**：跃升召下巨刃，广域重击断腿，冷却 7.5 秒 |
| R | 随时重新开始 |
| Enter | 开始、恢复、死亡后重开 |
| Esc | 暂停 / 恢复 |

四个新增技能在地面和空中均可单键独立释放，使用各自冷却、不消耗磁核。游戏内常驻技能栏显示按键、机制和剩余冷却，标题页也有完整说明。推荐 `Q 聚敌 → U 双月 → J 连斩 → E 穿阵`，或 `Q 聚敌 → O 裁决 → I 挑空追击`；各招可独立使用，不依赖固定连招。

右上角有静音和暂停按钮。失去焦点或页面隐藏时自动清空输入并暂停。

## 战斗设计

- **轻击压制 → 重击拆解 → 挑空落刃**：轻斩第三段力度更重；攻击可在一定收招阶段接下一招。提供短输入缓冲、地面近身辅助、跳跃缓冲和闪身取消。
- **命中才触发顿帧**：轻击约 48 毫秒，重击约 90 毫秒，蓄力重击约 125 毫秒。冻结角色、敌人与相机，粒子只做轻微延续；命中姿态停在切入阶段，随后正常恢复。
- **两种敌人**：锈色斧兵近身劈砍；蓝灰枪兵在中距离瞄准、突刺。红色圆弧与地面箭头提示前兆，攻击后存在可反击的恢复期。
- **真实分段断肢**：连斩累计肢体损伤或蓄力重击可拆下持械臂；空中下劈可断腿。脱离的肢体连同兵器旋转飞散、落地弹跳并保留数秒。断臂敌人失去武器、攻击距离和伤害降低，改用贴身攻击；断腿敌人姿势降低、移速下降至约三成、突进距离缩短。
- 持续刷波，每波间隔约 1.25 秒。清波修复 18 点装甲并补充磁核；每四次击杀修复 12 点装甲。磁核随命中、击杀和时间恢复，闪身擦过杀招可额外恢复。
- 无全屏闪白、无持续震屏。各类挥击、命中、断械、落地、挑空和闪身使用不同合成音色。

## 文件组织

```text
game.html                 最终单文件成品（含脚本、样式、字库、字体授权）
src/index.html            UI 与结构
src/style.css             界面与响应式布局
src/audio.js              Web Audio 音效合成
src/game.js               输入、战斗、AI、物理、波次与真实状态接口
src/skills.js             四个独立技能、持续伤害对象、聚敌与技能冷却
src/skill-render.js       磁涡、裂轨、双月与天炉巨刃的程序化视觉
src/render.js             程序化场景、骨架姿态、分段肢体和特效
skill_manifest.json       本轮四技能名称、实际操作与效果清单
tools/build.mjs           将上述文件打包为 game.html
tools/subset-font.py      中文字体子集生成过程（成品重建不需要运行）
tools/browser-libs.py     受限 Linux 自测环境的浏览器依赖准备工具
assets/FoundryCJK.woff2    Noto Sans CJK SC 的游戏文字子集
assets/FONT-LICENSE.txt   SIL Open Font License 1.1
tests/smoke.mjs           完整浏览器验收
tests/browser.mjs         浏览器启动与仅测试时使用的只读内部观察钩子
tests/skills.mjs          四技能的七组真实键盘实战验收
tests/skills-results.json 四技能验收结果
tests/results.json        原战斗十组自动验收结果
tests/*.png               验收截图
```

构建无需 npm 依赖：

```sh
node tools/build.mjs
```

开发测试需 Node 22 与 Playwright Chromium：

```sh
npm install --no-bin-links
node node_modules/playwright/cli.js install chromium
npm test
```

若 Linux 缺少 libnspr4 / libnss3 / libasound2，可以安装系统浏览器依赖；本环境无提权权限，使用 `python3 -I tools/browser-libs.py` 在独立临时目录解包运行库，测试脚本会自动使用它们。此过程仅为开发自测，最终游戏与这些依赖无关。

## 验收记录

在真实 Chromium 中通过原战斗十组测试及新增技能七组测试：

1. 初始就绪状态、只读 `window.combatBenchState()`、内嵌字体。
2. Enter 开始、左右移动、二段跳、空挥不触发顿帧。
3. 正常键盘操作蓄力断臂、真实肢体对象与命中停顿。
4. 磁升击飞、空中 K 断腿及存活敌人的肢体状态改变。
5. 闪身取消、无敌窗口与冷却、主动敌人的前兆与玩家受伤。
6. 连续连斩、击杀、连击及第二波敌人刷新。
7. 失焦时清空输入并暂停、恢复后不持续卡键。
8. 静音开关、阻止游戏按键默认滚动、960×540 和 1920×800 布局。
9. 不攻击时自然死亡、血量归零、Enter 重开并清零战斗计数。
10. `sandbox="allow-scripts"`、音频 API 不可用回退、`file://` 直接运行。

新增技能另通过：Q 真实聚敌与连斩衔接；E 路径命中、延迟爆裂与断臂；U 双向飞刃和自由行动；O 跃升、范围断腿与重顿帧；独立冷却和重复按键限制；四技能空中释放、失焦清理、重开清理；960×540 技能栏可见和按键默认事件阻止。测试仅观察真实状态并发出正常键盘输入，不直接制造命中。

最终验收零页面脚本异常、零外部 HTTP(S) 资源请求。测试期间发现并修复了首次断肢坐标格式导致动画中断的问题；也调整了顿帧时的命中姿态并内嵌中文字库。状态接口从真实玩家、敌人和命中/断肢计数生成，没有测试专用伤害、无敌或假计数。
