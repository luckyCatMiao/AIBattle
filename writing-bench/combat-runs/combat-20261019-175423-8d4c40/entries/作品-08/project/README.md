# 绯刃 · 月下斩

一个可直接在桌面浏览器离线游玩的横版动作战斗试玩。全部画面、特效、音效均为程序化生成，最终交付为单文件 `/workspace/game.html`，不依赖网络、CDN、图片或音频外部资源。

## 核心体验

- **快节奏三连斩**：`J` 三段连斩，前段命中后可取消后摇衔接下一段；第三段挑空，可跳跃追击进入空中连段。
- **蓄力重斩**：`K` 点按为快速重斩，按住可蓄力；满蓄力斩击会横扫附近关节，一次斩断多条肢体。空中按 `K` 为下坠震地。
- **疾闪**：`L` 地面/空中冲刺，前段有无敌帧；冲刺中按 `J` 触发突进斩，可穿过敌人与弩矢。
- **见切弹反**：`I` 约 290ms 的弹反窗口，成功后短暂慢动作、敌人失衡、回复少量生命；也可弹反弩矢并反射。
- **命中顿帧**：只有实际命中才触发。轻击约 0.045–0.075s，重击约 0.095–0.135s，斩断肢体/弹反另加冻帧与短慢动作；震屏幅度克制，没有连续震屏或满屏闪白。
- **肢体破坏**：斧傀、弩傀、疾爪傀均有分段骨架（上臂/前臂、大腿/小腿、头）。蓄力重斩、连段与弹反反矢可以打断关节，肢体作为带关节与武器的实体残肢飞出、落地、弹跳、燃尽，并在敌人身上留下发光断口。断臂会移除武器或射击能力；断腿会降低移动、无法扑击；斩首直接击杀。
- **四独立技能（1–4）**：右下角技能栏实时显示按键、名称与冷却。技能可打断攻击后摇，各自独立冷却：
  - `1` **月轮斩**：环身回旋三连斩并终结挑空，周围多段命中；冷却 4.5s。
  - `2` **影渡**：瞬身穿过最近目标，回身十字斩，高额断肢并触发短暂慢动作；冷却 6.5s。
  - `3` **千樱葬**：展开樱色领域，对全场敌人连续四段樱刃斩击并终结爆发；冷却 11s。
  - `4` **断界**：蓄势后向前斩出贯穿战场的月金色巨浪，粉碎前方所有肢体；冷却 15s。
  - 连续按下不同技能键会排队依次施放，避免连招时吞输入；冷却中按下会显示拒绝反馈。
- **持续试玩**：无尽波次，间隔约 2 秒；每次击杀回复少量生命，破阵回复 14 点。死亡后按 `R` 或 `Enter` 立即重开。

## 敌人

| 敌人 | 行为 |
| --- | --- |
| 裂斧傀 | 追击后高举巨斧重劈（地面扇形预警）；远距离会跃起砸地；双臂尽失后改为头槌冲撞。 |
| 弦弩傀 | 保持距离瞄准射击（激光预警）；失去持弩臂后无法射击，转为近身踢击。 |
| 疾爪傀 | 快速贴身爪击或蓄力飞扑（落点预警）；失去双臂后改为撕咬。 |

## 操作

`A/D` 或 `←/→` 移动 · `Space` 跳跃/二段跳 · `J` 连斩 · `K` 重斩（按住蓄力） · `L` 疾闪 · `I` 见切弹反 · `1/2/3/4` 四项独立技能 · `R` 重来 · `Enter` 开始/再战。鼠标仅用于开始和静音按钮。技能操作同样显示在标题页与战斗 HUD 右下角技能栏中。

## 构建与文件

- `src/parts/*.js`：按功能拆分的游戏源码（工具、音频、状态/输入、特效、玩家、技能、敌人、流程、绘制、UI、启动）。
- `src/style.css`、`src/index.html`：页面模板。
- `src/assets/CombatSerif-subset.ttf`：从 Noto Serif SC 抽取的游戏用字子集，构建时以 base64 内嵌，确保无系统中文字体时也能正常显示。Noto Serif SC 采用 SIL Open Font License 1.1。
- `build.mjs`：无依赖构建脚本，将源码与字体打包为 `game.html`。
- `skill_manifest.json`：四项技能的试玩用清单（名称、操作、效果简述）。

```bash
cd /workspace
node build.mjs      # 生成 game.html
```

## 启动稳健性

- 游戏脚本解析完成后立即初始化并暴露 `window.combatBenchState()`，`ready` 不再等待字体加载；内嵌字体并行预热，不阻塞开局。
- 启动逻辑带重试兜底；字体加载失败时自动回退系统中文字体，不影响游戏运行。
- 所有关键输入、窗口失焦、隐藏标签页、重置、沙箱 iframe 与静音切换均做了防御处理。

## 自测记录

使用真实 Chromium（Playwright headless）对 `game.html` 做了交互与视觉检查：

- 标题页 `Enter` 与鼠标点击均可开始；开始后 1 秒内敌人进入可战斗状态。
- `window.combatBenchState()` 只读（不可写、不可配置），字段齐全且随战斗真实变化；轻/重攻击命中时 `hitCount` 增加，断肢时 `limbBreakCount` 增加。
- 测得的命中冻帧：轻击约 0.045/0.050/0.075s，重击约 0.095s，满蓄力约 0.13s，且空挥为 0；冻帧后平滑恢复。
- 蓄力重斩单次可斩断 5 处肢体；断臂后弩傀 `canShoot=false`，失去持弩臂的弩傀改为近战。
- 弹反成功触发慢动作、敌人失衡与 3 点回复；成功弹反弩矢后生成反射弹并命中敌人。
- 静止不动约 15 秒会被两名斧傀击杀；死亡后 `playerAlive=false`、`playing=false`，按 `R` 后状态完全重置。
- 在 960×540、1024×768、1280×720、1920×800 视口下布局正常；窗口失焦后按键状态清空，移动会自然停止。
- 在 `sandbox="allow-scripts"` 的 iframe 中正常启动、加载内嵌字体并响应键盘；1–4 技能在沙箱中同样可触发并造成伤害。
- 四项技能逐项实测：均可独立由对应数字键触发，冷却互相独立；冷却中再次按键会显示拒绝反馈且不会重复施放；技能可取消攻击/蓄力/冲刺并带完整无敌帧。
- 实测技能效果：月轮斩多段命中并断肢；影渡产生位移穿越并命中；千樱葬对全场多波命中；断界命中前方敌人并一次粉碎多处肢体；四项技能在 Chromium 与 Firefox 中均无运行异常。
- 空中施放、攻击中取消接技能、重开后冷却清零、无 `AudioContext` 环境与沙箱环境均通过测试。
- 删除 `AudioContext` 后游戏仍可正常运行，静音按钮照常工作；键盘事件已阻止默认滚动。
- 在完整 Chrome（非 headless shell）中进行了 90 秒随机输入、缩放、重开、静音与点击压力测试；在 Firefox 中完成了开始、战斗、锁定目标与断肢测试；均无页面异常、未处理的 Promise 拒绝或崩溃。

调试用只读快照（可选）：在 URL 后加 `?debug=1` 可访问 `window.__combatDebug()`，仅供自动化测试观察位置/状态，不参与游戏逻辑，也不影响 `combatBenchState`。

> 说明：音频为 WebAudio 实时合成，已在浏览器中无报错运行并验证静音切换；由于测试使用无声 headless Chromium，未进行人耳听感评估。
