# Font notice

`CombatSerif-subset.ttf` is a subset of **Noto Serif SC SemiBold**, generated from the
Google Fonts-hosted font for the characters used in this game.

Noto Serif SC is licensed under the SIL Open Font License, Version 1.1.
The font is embedded into the final `game.html` as a base64 data URI so the game works
offline and has consistent CJK typography on systems without Chinese system fonts.
