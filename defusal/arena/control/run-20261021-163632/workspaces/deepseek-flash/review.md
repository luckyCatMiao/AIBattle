## 3. 复盘结论

### 3.1 r3-g1 赢在进攻转化与两个手枪局

- R1–R3 连续三次打 B，三次都成功下包，并且都在守方全灭后结束；这是 `ATK_REPEAT_WIN=1`（赢下才复点）最直接的正面样本。没有出现“下包后被拆”的老问题。
- 三回合的交换都很薄：5/4、5/3、5/4，并不是碾压；但进攻方每次都把最后 1–2 人留在场上，说明进点后的残局处理正常。
- R2 我方全步枪、R3 四人步枪一人 SMG，sol 仍是 SMG；经济优势来自 R1 手枪局获胜，R4 半场重置后再次赢下手枪局，比赛没有进入经济劣势。
- 结论：**进攻端“3+2 分路 + 携带者后置 + B 点复点”在这张图上有效，不应因为 g2 的失败就推翻复点规则。**

### 3.2 r3-g2 输在第二半场进攻：0 杀、0 下包

- R4 是半场重置后的手枪局，双方都是手枪；按战后金钱可反推双方都买了护甲（我方每人 2050 = 150 剩余 + 1900 败方奖励，且无击杀奖励）。这是一次**经济对等的 5v5**，我方却 0 杀、5 人全灭，仅 17.70 秒。
- R5 因 R4 失败进入 SMG + 护甲 vs 步枪 + 护甲；20.15 秒内再次 0 杀、5 人全灭、未下包。
- 按 `choose_attack_site` 的代码路径，R4 没有下包，`ATK_REPEAT_WIN=1` 会在 R5 **自动换到另一点**。因此 R5 已经打过另一个点，仍然 0 杀。**“sol 只是重堆了我们打的某一个点”不足以解释这两回合；至少第二半场 sol 的防守在两个点上都赢下了第一波交火。**
- 两回合合计 0 杀 10 死、0 次下包，是本轮最明确的失败模式；优先于“猜点”问题。

### 3.3 防守端的关键发现：sol 在我方 4 个防守回合全部打 B（推断）

推断依据：我方防守是静态 5 人重堆（`STACK_N=5`，`COLLAPSE=0`），未下包时不会主动全队转点。因此“未下包且一方全灭”的回合，战斗基本发生在被重堆的那个点。

| 对局/回合 | 我方重堆点 | 战报事实 | 推断的 sol 攻点 |
|---|---|---|---|
| r3-g1 R4 | B（半场首个防守回合，`DEF_FIRST=B`） | 未下包，进攻方全灭，我方胜 | **B** |
| r3-g2 R1 | B（半场首个防守回合） | 未下包，防守方全灭，sol 胜 | **B** |
| r3-g2 R2 | 旧默认 `DEF_ALT1=1`：R1 已有一次 B 情报 → 预测 A | **B 下包**，sol 胜 | **B** |
| r3-g2 R3 | R1 记录 B、R2 下包 B，历史为 [B,B]，legacy 复读 B | 未下包，进攻方全灭，我方胜 | **B** |

- 4/4 指向 **B**。这与第 3 轮赛前基于历史运行倾向于认为“sol 会交替攻点”的判断相反；官方第 3 轮的直接证据优先。
- 唯一走到 `len(hist)==1` 分支的是 **r3-g2 R2**：旧默认 `DEF_ALT1=1` 会把“复读 B”改成“预测 A”，而 sol 实际继续打 B 并成功下包。该回合我方 2 杀 5 死、31.90 秒丢掉，是 g2 防守 1–2 中最可疑的一回合。
- 这不是“防守结构崩了”：g1 R4 与 g2 R3 都在 B 点守住了；问题主要是**一次预测方向的错误**。

### 3.4 经济与手枪局

- r3-g1 赢下 R1、R4 两个手枪局，R2/R3 因此有步枪对 SMG 的优势。
- r3-g2 输掉 R1、R4 两个手枪局，R2/R3/R5 长期是 SMG 对步枪；R2、R5 的失利有明显经济因素。
- 但 **R4 是经济对等的手枪局，仍然 0–5**，所以经济差不是 g2 进攻失败的唯一解释；不能把问题全部归因于“输手枪局”。

## 4. 本轮改动

以下改动均在两场官方对局结束后完成，**未参加 r3-g1 / r3-g2**。代码上只改 `agent.py`，`entry.json` 与 5 个受保护文件未动。行号以本次提交为准。

| # | 改动 | 位置 | 新默认 | 行为 | 依据 |
|---:|---|---|---|---|---|
| 1 | `DEF_ALT1` 默认 **1 → 0** | `agent.py:90` | **0** | 半场内只有一次已知攻点时，**复读该点**，不再强制预测另一点；有两次及以上情报时仍走 legacy 的“最近两点不同则回到前一点、否则复读”规则 | 官方 r3-g2 R2：旧值预测 A、sol 实际 B 下包；官方 4/4 防守回合 sol 都打 B |
| 2 | 新增 `ATK_RUSH_AFTER_ZERO`，默认开启 | `agent.py:64`、`agent.py:647`、`agent.py:1567`、`agent.py:1719`、`agent.py:1813` | **1** | 若**上一个进攻回合 0 杀且未下包**，本进攻回合改为 5 人单入口集中推进：关闭 3+2 分路、关闭携带者后置等待，把 5 个人压进同一次交火 | 官方 r3-g2 R4：0 杀/0 下包/17.70 秒被全灭；R5 换点后仍 0 杀 |
| 3 | 新增 `CARRIER_WAIT` 开关，默认保持 1 | `agent.py:66`、`agent.py:1788`、`agent.py:1813` | **1** | 正式行为不变；只用于本地对照“携带者是否后置等待” | 关闭等待的 A/B 明显更差（见 5.1），因此不采用 |
| 4 | 新增 `ATK_RUSH` 强制开关，默认关闭 | `agent.py:63`、`agent.py:647` | **0** | 仅供本地强制测试 5 人推进，不参与正式决策 | 实验项 |

改动 1 的代码路径：

```python
# agent.py:90
DEF_ALT1 = os.environ.get('AGENT_DEF_ALT1', '0') == '1'
```

`defense_stack_site()` 的 `len(hist) == 1` 分支现在返回 `hist[-1]`（复读），而不是 `('B' if hist[0] == 'A' else 'A')`。通常影响每个半场的第二个防守回合（第一次拿到单点情报之后）；如果 sol 以后恢复交替，`len(hist) >= 2` 的 legacy 规则会在下一次情报后自动纠正，代价最多一个回合。

改动 2 的触发逻辑：

```python
# agent.py:647
def attack_rush_now(obs, brain):
    ...
    prev = 上一个“我方进攻”回合
    k_prev = roundLog[prev] 中我方累计击杀
    k_before = roundLog[prev-1] 中我方累计击杀（prev==1 时取 0）
    planted = roundLog[prev].bomb.state in ('planted','defused','exploded')
    if planted is False and (k_prev - k_before) <= 0:
        本回合 rush = True
```

- 在 `build_plan()` 中，`rush=True` 会跳过 `SPLIT_ATK` 分支（`agent.py:1719`），并让 `carrier_wait=False`（`agent.py:1813`），即 5 人从单入口一起压上。
- 用官方战报数据做了触发核对：
  - r3-g2 R5：上一进攻回合 R4 为 0 杀、未下包 → **触发 True**；
  - r3-g1 R2：上一进攻回合 R1 为 5 杀、已下包 → **触发 False**。
- 该改动只在“上一进攻回合完全没有打出击杀且没下包”时生效，正常回合不受影响。

## 6. 局限

1. **没有官方回放/坐标/种子**：3.3 的“sol 4/4 打 B”是反推，不是逐帧证据。若实际战斗发生在转点途中，结论需要修正。
2. **g2 进攻失败的具体原因不能完全证明**：R4/R5 都是 0 杀、0 下包，但没有位置数据，无法区分“进点路线被长枪线架死”“分路被逐个吃掉”“携带者后置导致 4v5”等假设。`ATK_RUSH_AFTER_ZERO` 是对这一失败模式的保守修正，本地 A/B 没有可测收益，不能声称它一定能在正式对局中翻盘。
3. **`DEF_ALT1=0` 是对手特异性的**：它对“复读 B”的 sol 更好，但对偏交替的 r1 防守回合率低约 6.4 个百分点。样本只有两场官方对局，不能外推成通用规律。
4. **本地机器人不是 sol**：r1/r2 是冻结的旧机器人，它们的选点、交火和经济习惯与 sol 不同；本地回归只能证明“没有技术故障和明显回归”，不能预测对 sol 的胜率。
5. **累计数据有 ±1 噪声**：g2 R2/R3/R5 的逐回合击杀/死亡有 ±1 不闭合；R2 与 R3 的差额方向相反、互相抵消，净值上 R5 多 1 个 sol 死亡。“0 杀”结论不受影响，但不要用单回合的 1 杀差异做结论。
6. **耗时是本地测得**：正式环境若有额外开销，仍有约两个数量级余量；不应把 66.77 ms 当作正式环境的最大值。
7. **改动 2 的触发样本很少**：独立 A/B 的整场回合率与关闭时只差 0.28 个百分点（49.86% vs 50.14%），本地回归中也没有可测差异；因此它的价值主要是“避免重复已验证的失败结构”，而不是已被本地数据证明的提升。
