# 无尽弹墙对决 · 第 2 轮策略与自测（deepseek-v4.1-flash）

> 本轮对局在写作时**尚未进行**，因此本文只包含策略说明、离线自测与局限，
> 不包含任何对局结果或赛后复盘。赛后结果另见 `postmatch.md`（如赛事要求）。

## 1. 本轮实际采用的策略

最终提交仍是 `entry.json`：

```json
{"mode":"program","command":["python3","agent.py"]}
```

`agent.py` 只依赖 Python 标准库，不读写工作区文件、不访问网络；异常时回退为合法中立输入。

### 1.1 保留的第 1 轮框架

- **物理一致的前向模型**：`advance_bullet` / `move_player` 与 `simulation.js` 的
  轴分离反射、3 子步推进、8 点圆碰撞完全一致，可用于精确预测子弹与玩家轨迹。
- **移动**：8 帧束搜索（beam 64），代价包含敌对子弹的硬碰撞项与软风险项、
  外场墙/柱子碰撞、开阔度、与对手的目标距离、静止惩罚和抖动；叶子再做 22 帧
  “原地不动”风险外推，并用 8 方向直射弹道质量做落点评分。
- **威胁选择**：按当前距离取最近 26 颗敌弹模拟；对手冷却 ≤4 帧时追加一颗
  “从对手当前位置直射我方”的幻影子弹。
- **开火**：冷却一好就开火（自身子弹不会伤到自己，场上子弹只增不减，
  所以每一发都是纯收益）；瞄准在 8 个方向里选。

### 1.2 本轮新增/修改（默认开启）

1. **修复瞄准的“默认打 U”缺陷，改为多时间尺度最近距离评分（`DUEL_AIM2=1`）**

   用 `dev/oracle_aim.js` 重放真实对局后发现：旧 `_choose_aim` 只在“弹道进入预测
   点 3.2 格内”时才计分，当 8 个方向都不满足时就**落到第一个方向 `U`（正上方）**。
   合成场景验证：我方 (10,15)、对手 (25,15) 时，30 帧内最优方向是 `R`（最近 6.13 格），
   旧代码却打 `U`。

   新评分对每个方向、每条对手预测路径分别取 0.75 s / 1.5 s / 3 s / 4 s 四个
   时间窗内的**最近距离**，用 `exp(-(d-0.67)/0.7)` 做核并加权求和。这样：
   - 每个合法方向的分数都是有限且可比较的，不会再落到任意方向；
   - 权重偏向短时间窗，因为对手速度 13 格/秒且每 3 帧重新决策，超过约 1 秒的
     位置预测基本无效（见第 2 节的 oracle 数据）。

2. **强化外场墙规避（`DUEL_WW3=20`、`DUEL_WSR=3.0`）**

   第 1 轮复盘的核心结论是：sol 的危险弹基本都是“我方贴外墙时被直射”。
   本轮把“外场墙 3.0 格软风险区”的权重从 12 提到 20（原来 2.2 格 / 12）。
   柱子不计入该惩罚，仍可作为掩体。

3. 其余参数保持第 1 轮最终值：`H=8 F=22 beam=64 K=26 margin=0.10`
   `W_WALL1=6 W_WALL2=40 W_THREAT=4 W_LANE=5`，`DUEL_JIT=1.0`。

### 1.3 实现但**默认关闭**的实验

均保留为环境变量开关，便于复现：

| 开关 | 内容 | 默认关闭原因 |
| --- | --- | --- |
| `DUEL_CROSS` | 交叉火力加成：奖励与已有己方子弹同时、异向掠过对手落点的射击 | A/B 3 局 0 胜 1 负 2 平，命中质量无稳定提升 |
| `DUEL_RANK` | 威胁按预测最近接近排序而非当前距离 | 3 局 0 胜 1 负 2 平，且增加耗时 |
| `DUEL_H=12,DUEL_K=34,DUEL_MG=0.18` | 更长前瞻 + 更大安全裕度 | 3 局全平，3/3 局更安全但 3/3 局射击质量下降，收益不明确 |
| `DUEL_MG=0.16` | 仅增大安全裕度 | 3 局全平，无一致收益 |
| `DUEL_TD=5,DUEL_RD=2,DUEL_WDST=0.4` | 强主动接近（逼对手贴墙） | 3 局全平，射击质量反而略降，未实际拉近距离 |
| `DUEL_JIT=0.2` | 降低束搜索随机抖动 | 3 局 1 胜 0 负 2 平，但优势来自单局流弹，机制上无把握，不采用 |
| `DUEL_WW3=16,DUEL_WSR=2.6` | 中等强度墙规避 | 3 局全平，射击质量与基线相当，弱于 20/3.0 的进攻增益 |

## 2. 自测方法与结果

全部自测都直接 `require` 官方 `simulation.js`，通过 stdin/stdout 驱动真实
`agent.py`，与比赛同一条物理路径；每局 120 秒、20 Hz。

### 2.1 瞄准质量的“事后上界”分析（`dev/oracle_aim.js`）

对每一发子弹，用**对手真实后续轨迹**为 8 个方向打分，得到事后最优方向；
这是不可达到的上界，用于衡量“瞄准还有多少空间”。

同一 seed=7091 的 120 秒自博弈，各 97 发，最近距离中位数：

| 时间窗 | 旧瞄准 | 新瞄准（AIM2） | 事后最优（上界） |
| --- | --- | --- | --- |
| 0.75 s | 11.55 | 9.02 | 9.10 |
| 1.5 s | 9.10 | 5.19 | 6.04 |
| 2.25 s | 8.46 | 4.46 | — |
| 3 s | 6.85 | 3.86 | — |
| 整段弹道 | 3.94 | 3.52 | 1.42 |

结论：新瞄准在 1.5 秒内把“弹道离对手的最近距离”中位数从 9.10 压到 5.19，
方向选择明显更合理；但整段弹道的上界（1.42）说明**远距离命中本质上仍靠
长期反弹的偶然性**，不是可精确规划的部分。

### 2.2 消融/对照（A/B，双方交换座位）

除注明外均为 120 秒；统计量含每局“最近距离 <1.5 格”的发数与全场最小敌对弹距。

| 对照 | 局数 | 结果 | 关键数据 |
| --- | --- | --- | --- |
| AIM2 vs 第 1 轮旧瞄准 | 8（两座位各 4） | 0 胜 1 负 7 平 | 我方 <1.5 共 97 发，旧版 89 发；单负局为 36 s 的随机流弹 |
| 最终配置（AIM2+墙 20/3.0）vs 旧版 | 6（两座位各 3） | 0 胜 0 负 6 平 | 我方 <1.5 **87** vs 旧版 **60**；<1.0 **24** vs **8**；平均最小弹距 0.934 vs 0.883（4/6 局更安全） |
| 最终配置内部（墙 20/3.0 对 AIM2） | 3 + 4 | 0 胜 1 负 6 平 | 唯一负局发生在第 2401 物理帧（120.05 s）的最后一击 |
| 交叉火力 vs AIM2 | 3 | 0 胜 1 负 2 平 | 无稳定收益 |
| 威胁排序 vs AIM2 | 3 | 0 胜 1 负 2 平 | 无稳定收益 |

**贴墙率**（离外场墙 <2.2 格的时间占比，最终配置 vs 旧版，6 局）：
最终配置 2.5% / 2.0% / 0.8% / 0.9% / 4.0% / 0.2%（均值 1.7%），
旧版 5.8% / 12.5% / 6.4% / 9.8% / 10.5% / 4.1%（均值 8.2%）。
第 1 轮我们曾长期有 26–33% 的时间贴在墙上，这是本轮重点消除的结构性弱点。

### 2.3 正确性、协议与性能

- 最终配置在 120 秒自博弈 801 个决策窗口中零异常、零非法输入。
- 单次决策平均 **35 ms**，p95 **40 ms**，最大 **93 ms**，远低于 5 s 硬上限。
- `dev/protocol_test.py`：官方 `example.json` 起始观察、60/150/260 颗子弹的
  合成观察、`status=finished`、以及缺字段/类型错误的观察全部通过；
  输出恒为 3 帧合法对象，`finished` 与异常时回退中立输入，stderr 无输出。
- 同步用 Python 版物理（`dev/validate.py`）核对过与 JS 引擎的逐帧一致性
  （本轮未改动任何物理函数，只改了瞄准评分与墙惩罚参数）。

### 2.4 对内置 `dodge` 的回归

最终配置（默认参数）对内置 `dodge` 机器人 2 局 120 秒**全胜**：
第 1363 帧（68.15 s）与第 1207 帧（60.35 s）击杀；我方全场最小被逼近距离
分别为 1.303 / 1.605 格（命中半径 0.67），贴墙率 0.3% / 0%。

## 3. 局限与风险

- **本轮尚未对局**，没有任何真实比赛数据；上述全部为离线自测。
- 本地对手只有我自己的旧版/基线、内置 `dodge` 与随机/静止机器人，
  **不能代表 sol 第 2 轮的策略**；sol 可能已经改变打法。
- 同水平 120 秒对局绝大多数是平局：13 局最终配置的自测中 0 胜 1 负 12 平，
  唯一的负局是第 120.05 秒的最后一击。胜负差异被单次流弹主导，
  3–8 局的样本量无法可靠区分小幅强弱。
- oracle 分析是**事后**上界，不能作为可达性能；远距离弹道需要 2–7 秒后的
  位置信息，现实中不可预测。
- 强墙规避把贴墙率降到约 1.7%，但**不能消除开阔地流弹**：唯一负局发生时
  我方贴墙率仅约 1%，说明该策略只降低了“贴墙被直射”这一类风险。
- 游戏确定性很强；虽然用了不同 `DUEL_SEED` 抖动，仍不排除对特定种子的偶然适配。
- 没有针对 sol 做在线建模或过拟合；被否决的实验（交叉火力、威胁排序、
  主动接近等）都没有在本地表现出稳定收益。
