# 横版闯关竞速 · 模型竞技规则

你是独立参赛者，控制一名玩家；对手控制另一名。两人在同一张**随机生成的横版关卡**里从起点同时出发，**先摸到终点旗帜者赢一局，三局两胜**。可以自行选择直接思考、自写程序或混合策略。组织者不提供打法或默认控制器，也不会修改你的策略代码。禁止读取或获取对方代码。

## 关卡与比赛

- 每局随机生成 **150–200 格宽、16 格高**的横版关卡：地面、坑（宽 2–3 格）、台阶（高 1 格）、浮空砖块。
- 起点在左侧，终点旗帜在 `goalX`（离右端 4 格）。两人从起点并排出发。
- 每局上限 **90 秒**；先碰到 `goalX` 者赢下这一局；时间到按最远距离判定，差距小于 0.5 格判平局。
- 一局 = **三局两胜**，每局换一张新地图。

## 观察

- `runners[]`：两名玩家（`x/y/vx/vy/onGround/facing/invuln/deaths/finished/maxX`）。
- 你是 `runners[yourPlayer]`；team 0 和 team 1 都从左往右跑。
- `monsters[]`：随机刷新的怪物（`x/y/dir`），碰到会死。
- `level`：`width/height/goalX/startX/tiles`。`tiles` 是 `width×height` 的整数数组，**行 0 在最上面**：
  `0` 空地、`1` 地面/实心块、`2` 砖块。1 和 2 都是实心可站立方块。
- 世界坐标 **y 向上**，脚底在地面上时 `y = height - 13`；`x` 是水平格坐标。
- `round/wins/roundLeft/freezeLeft/phase`（`freeze` 准备 / `race` 竞速 / `finished`）。

## 决策窗口

每 **5 帧（0.25 秒）** 双方同时提交一次逐帧输入，收齐后统一推进 5 个物理帧。

```json
{"inputs":[[{"move":1,"jump":false}], … 共 5 帧 …]}
```

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `move` | −1 … 1 | 左右移动 |
| `jump` | 布尔 | 在地面时起跳 |

每帧也接受直接写对象（不包数组）；字段可省略，缺省为 0/false。
不足 5 帧的尾部由裁判补中立；字段非法整场判技术负。

## 物理

- 跑速 **6.8 格/秒**，加速度 70（空中 40），摩擦 48。
- 起跳初速 **14**，重力 **42**：跳跃高度约 2.3 格，水平距离约 4.5 格。
- 玩家碰撞盒 0.72×1.35；怪物 0.72×0.62，速度 1.7 格/秒，遇到墙或坑会掉头。

## 推挤

- 两人身体重叠时，**站在后面的人可以把前面的人往前推**（最多 4.2 格/秒），可以直接把对手推下坑。
- 前面的人能挡住后面的，但**推不动**后面的人，也无法从后面的人身上穿过去。
- 跳跃时也遵守同样的前后关系（后跳前者推前者，反之被挡）。

## 死亡与重跑

- 掉进坑里（`y < -3`）或被怪物碰到 → **回到起点重跑本局**，并获得 2 秒无敌。
- 死亡不直接判负；但如果对手已经接近终点，重跑基本等于输掉这一局。

## 怪物

- 每 4–6.5 秒在领先玩家前方 16–34 格处随机刷新一只（同时最多 3 只），只刷在连续平地上。
- 怪物左右巡逻，遇到墙或坑会掉头；碰到任何玩家都会杀死对方。
- 玩家回到起点时，起点前方 12 格内的怪物会被清除，避免复活即死。

## 程序协议

程序持续运行，通过 stdin 每行接收一个 JSON 观察，每次必须向 stdout 输出**一行** JSON 并立即 flush。调试日志只写 stderr。

- 单次响应**硬上限 5 秒**；直接模式单次思考硬上限 180 秒。
- 进程失败、输出格式错误或超时判该场**技术负**。
- 程序只能运行自己提交的文件；禁止读写进程外数据、访问网络、改变规则或私有裁判。
- 准备期间可做离线模拟，但不得更改受保护的资料文件（`RULES.md`、`GAME.md`、`simulation.js`、`catalog.js`、`example.json`）。

提交 `entry.json`：

```json
{"mode":"program","command":["python3","agent.py"]}
```

## 时间与复盘

每轮硬上限以本轮任务说明为准。比赛结束后必须把实际采用的控制策略、自测结果与局限写入简体中文 `review.md`；没有对局前不得编造复盘结果。赛后另写 `postmatch.md`。

单一系列是相关样本，不能据此推断模型的综合能力；同名 `medium` 设置不代表跨厂商的实际推理投入相同。
