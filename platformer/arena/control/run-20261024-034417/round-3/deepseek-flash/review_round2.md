> 数据来源：`r2-g1.json.gz`、`r2-g2.json.gz`（20Hz，逐物理帧回放）+ 公开战报。
> 复算校验：把回放里的每个观察按窗口喂给本轮提交的 `agent.py`，两场分别 839 / 585 个窗口，
> 输出与实际提交输入 **逐帧完全一致（diffs=0）**，因此下面的分支、输入与反事实都可以追溯到提交代码。
> 口径说明：公开战报的 `deaths` / `maxX` 只取**最后一个子局**的快照；本文按整场回放统计。
> `duration` 字段（30.21 / 31.3）与回放时间轴（209.65s / 146.30s）不是同一口径，本文以帧数 × 0.05s 为准。

## 〇、关键结论

1. **两场结果：`r2-g1` 0:1 负于 sol，`r2-g2` 1:1 平。** 六个子局合计：我方 1 胜、2 负、3 平。
   唯一一胜是 `r2-g2` 第 3 局（180 格图，我方 176.19 到终点）。
2. **两次直接决定子局生死的推挤事件都是“后方被压到 4.2 格/秒”这条规则：**
   - `r2-g1` R1：我方在 sol 后面，过 4 格坑时后位接触 3 帧，被压到 4.2，落地帧少前进约 0.10 格，
     撞上 x=92 的坑壁后掉坑（x=91.64）。反事实复算：若不施加推挤，同样输入可在 x=91.70 安全落地。
   - `r2-g2` R3：sol 在我方后面，过 123–124 两格刺时后位接触 3 帧，sol 被压到 4.2，
     落点从无推挤时的约 x=125.3–125.6 变成 x=124.96，正好踩在最后一格刺上死亡；我方以 176.19 到终点。
3. **`r2-g2` R1 的失利由几段相对位置变化叠加：** ① x≈57–65 的“2 格坑 + 锯齿”走廊，
   先到者被迫空中刹车（领先 0.99 → 落后 0.84，摆动 1.83 格）；② 中段我方一度追回到落后 0.75；
   ③ x≈154–155 我方在后追尾，无推挤反事实显示 frame 480 本可领先 0.07、实际落后 0.75
   （约 0.82 格摆动），随后 x≈160 的锯齿刹车又扩大约 0.60 格；最终 180.29 对 181.94，差 1.65 格。
4. **本轮新增的“防被推”改动没有覆盖本轮的实际失分模式。** `search_survive_push` 只在“对手在身后”
   时启用：`r2-g1` 一次都没触发（PUSH 窗口 0），`r2-g2` 触发了 20 个窗口但都是 sol 在身后；
   `IDLE-ANTIPUSH` 两场 0 次触发。真正杀死我们的“我方在后、主动追尾前车”完全没有建模。
5. **三张 3 连刺卡死图都拿到了理论 maxX**（`g1` R2 = 113.07，`g1` R3 = 25.03/25.07，
   `g2` R2 = 61.08/61.07），三局平局是预期结果；`g1` R3 的 0.04 格差距仍远小于 0.5 格判平线。

## 五、本轮提交的改动与实战效果

**效果评估（按决策窗口统计）：**

- `r2-g1` 839 个窗口：`IDLE 641`、`NORM 65`、`MAXX 15`、`DEATH 3`、`FALLBACK-AIR 2`；
  **PUSH 系列 0、IDLE-ANTIPUSH 0**。
- `r2-g2` 585 个窗口：`IDLE 255`、`NORM 82`、`AIR-FIRST 40`、`MAXX 23`、
  `PUSH-PLAN 16`、`PUSH-AIR 4`、`WAIT-SECOND 1`、`DEATH 3`；**IDLE-ANTIPUSH 0**。

结论：

1. **`r2-g1` 的致命问题完全不在本轮改动的覆盖范围内。** 推挤逻辑只判断 `opp.dx < 0`（对手在身后），
   而 R1 掉坑时是对手在前、我方在后主动追尾；我方作为后方被压到 4.2 的代价没有进入搜索模型。
   该局 `FALLBACK-AIR` 只出现在 frame 290/295，也就是已经起跳、无法补救的窗口。
2. **`IDLE-ANTIPUSH` 没有被实战检验。** 本轮的起点接触都是我方在后推 sol，不存在“待机时被身后
   对手推走”的场景；第 1 轮的 49 帧推人事件没有重演。
3. **`search_survive_push` 在 `r2-g2` 确实生效，但作用有限。** 它保护的是 sol 在身后时的我方；
   而 R3 的胜利来自“sol 追尾我方后自己吃 4.2 限速”，不是搜索主动规划出来的。
4. **真正的两处失分是“前车刹车/相位差”和“后位追尾”，都属于相对位置与对手意图建模，**
   不是本轮改的“被推落坑”模型。
