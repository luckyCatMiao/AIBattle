# 横版闯关竞速 · PLATFORMER ARENA

两名玩家在同一张**随机生成的横版关卡**里从起点同时出发，先摸到终点旗帜者赢一局，三局两胜。
可以推人、会被怪物追杀、掉坑或碰怪要**回起点重跑**。

- 游戏服务：<http://127.0.0.1:8814/>（`StartPlatformer.bat` / `npm run platformer`）
- 观战回放：<http://127.0.0.1:8815/>（`WatchPlatformerBattle.bat`）

## 比赛

| 项目 | 数值 |
|---|---|
| 关卡 | 每局随机 150–200 格宽、16 格高；地面、坑（2–4 格）、台阶、浮空砖块 |
| 机关 | 地刺、移动平台、食人花、旋转锯齿、塌陷砖 |
| 目标 | 先摸到终点旗帜（`goalX`，离右端 4 格） |
| 赛制 | 每局 90 秒，三局两胜，每局换新地图 |
| 超时 | 最远距离判定，差距 < 0.5 格平局 |
| 死亡 | 掉坑、碰怪、地刺、食人花、锯齿 → 回起点重跑，2 秒无敌，不直接判负 |

## 玩家与物理

| 参数 | 数值 |
|---|---|
| 跑速 | 6.8 格/秒（加速度 70，空中 40） |
| 跳跃 | 初速 14、重力 42 → 高度约 2.3 格、距离约 4.5 格 |
| 碰撞盒 | 0.72 × 1.35 格 |
| 推挤 | 后面的人可以推前面的人（≤4.2 格/秒），前面的人挡得住但推不动 |
| 怪物 | 0.72 × 0.62 格，1.7 格/秒，遇墙/坑掉头；每 4–6.5 秒刷新，最多 3 只 |
| 移动平台 | 2.4 × 0.36 格，周期 3–5 秒横跨坑；站上去会被带走 |
| 地刺 / 食人花 / 锯齿 | 碰到即死；食人花周期 3–4.6 秒、露出约 1.25 秒；锯齿半径 0.48、8 格往返 |
| 塌陷砖 | 站上去 0.55 秒后塌，3.2 秒后恢复 |

## 输入

每次提交 5 帧，每帧一名玩家：

```json
{"inputs":[[{"move":1,"jump":false}], … 共 5 帧 …]}
```

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `move` | −1 … 1 | 左右移动 |
| `jump` | 布尔 | 在地面时起跳 |

- 每帧也接受直接写对象（不包数组）；字段可省略。
- 不足 5 帧的尾部由裁判补中立；字段非法整场判技术负。

## 程序协议

```json
{"mode":"program","command":["python3","agent.py"]}
```

程序持续运行，通过 stdin 每行接收一个 JSON 观察，必须向 stdout 输出**一行** JSON 并立即 flush。
调试日志只写 stderr。单次响应硬上限 **5 秒**。

## 竞技评测

```bash
python platformer/arena/train.py --players deepseek-flash sol --rounds 3 --port 8816 --no-isolation
```

- 每轮 2 局，双方交换座位；3 轮共 6 局，每局随机地图。
- 准备阶段默认不设超时；本机直跑模式只把宿主 Claude Code 配置写进临时目录，凭据不进入项目、日志或回放。
- 回放逐物理帧存档（`r*-g*.json.gz`），`arena/audit.js` 会重新执行全部输入并逐帧比对。

## 本地对战

`StartPlatformer.bat` / `npm run platformer`：A/D 或 ←/→ 移动，W/空格 跳跃。
你控制左侧玩家，对手由练习电脑控制；点「开新局」会随机生成一张新关卡。
从后面顶住对手可以把人推下坑，但也要小心被怪物堵在坑边。
