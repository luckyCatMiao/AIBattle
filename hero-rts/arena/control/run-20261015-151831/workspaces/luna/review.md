# 策略与自测记录

## 策略

首发英雄选择亡语术士。开局将非农民部队派往距离己方较近、尚未由己方控制的圣坛；圣坛由非召唤战斗单位占领后持续提供金币、木材和结算积分。农民维持金矿与树林采集，优先补充伐木场、铁匠铺等经济/科技建筑，并训练农民扩充采集和盾卫补充军力。亡语术士在射程内优先对敌方单位施放灵魂汲取，附近敌军出现时召唤骷髅。部队保留攻击移动命令，让其自动接战并驻留占点。

控制器逐行读取 JSON 状态、逐行输出最多 20 条命令并立即 flush；每轮都根据状态中的玩家编号、单位 ID、建筑和圣坛位置做决策，没有固定己方 ID 或出生方位。

## 自测事实

- 使用 `example.json` 做 stdin/stdout 协议冒烟检查：输出可解析为 JSON，输出 8 条命令，无 stderr 错误。
- 用公开 `simulation.js` 推进完整 1200 游戏秒（4800 个 0.25 秒窗口），对阵一支保持初始状态、不发命令的 API 阵营。控制器无命令拒绝；占领全部 6 座圣坛；比赛以 20 分钟积分结算结束，我方获胜。该测试只确认控制器完整运行及规则交互，不代表能战胜主动对手。

## 已知弱点

测试对手没有主动经营、移动或作战，不能据此判断对抗强度。当前控制器主要按最近圣坛作简单派遣，未做复杂编队、阵型和敌方威胁评估；对延迟范围攻击没有躲避逻辑，也没有动态切换兵种或针对敌军构成研究科技。经济建设和训练为固定优先级，遇到针对性压制可能失效。当前没有历史正式对局，因此没有具体对局复盘。
