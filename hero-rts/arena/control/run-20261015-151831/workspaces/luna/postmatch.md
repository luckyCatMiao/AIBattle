# 赛后复盘：r1-g1 与 r1-g2

## 结果与范围

依据 `public_results.json` 及两份公开回放（`public-r1-g1.json.gz`、`public-r1-g2.json.gz`），两场使用同一地图种子（seed 1），双方交换座位。Sol 两场均胜：g1 用时 189.75 秒，比分 Sol 6999、Luna 1091；g2 用时 173.25 秒，比分 Sol 6139、Luna 1037。胜因均为对手城镇大厅全部被摧毁。双方 API 错误均为 0，无技术故障。

这是这两场对局中观察到的策略表现，样本仅为同种子、互换座位的两场比赛；不能据此推断模型整体能力高低。

## 决策时间线

- **开局至约 13 秒：双方都先争夺近侧圣坛，Sol 同时铺开地图控制。** 两场中 Luna 都把主力攻击移动到地图中央（g1 目标约 `(900,1000)`，g2 镜像到 `(2300,1000)`），并各自占下近侧圣坛，约 12.3 秒完成。Sol 开局则拆出部队前往两侧目标，并在约 23.6–24.6 秒拿下中央北、南圣坛；Luna 没有跟进争夺。Sol 因而较早获得更多控制点与经验来源。回放中的重复事件是逐帧快照累积，以上按实际发生时间去重。
- **约 20–30 秒：Luna 的中央集结出现早期损耗。** 两场在约 23.7–28.1 秒间，Luna 多个单位在地图中央附近（约 x=1485–1712、y=980–1069）死亡。同期 Sol 的部队仍在占点、发育；Sol 的英雄逐渐获得经验。Luna 的集中攻击移动没有转化为有效击杀或目标推进，反而削弱了可用军力。这是双方差距开始拉开的第一个清晰节点。
- **约 30–60 秒：Sol 的经济与兵力建设持续，Luna 的扩张停滞。** g1 中 Sol 的靶场约 19 秒完成，随后补农庄、奥术建筑及多个靶场；g2 也是 Sol 先建伐木场、农庄，继而建奥术建筑与靶场。Luna 两场都只见到早期伐木场、靶场/基础生产投入有限，后续没有与 Sol 相当的经济和生产扩张。到约 60 秒，Sol 人口约 38–39，Luna 约 22–27；Sol 已有更稳定的远程兵力和占点优势。
- **约 60–90 秒：英雄存活成为明显分水岭。** Luna 的死灵法师在 g1 约 64 秒阵亡、g2 约 58 秒阵亡；两场之后都保持死亡状态，未见重新召唤。Sol 的德鲁伊持续存活并升级（g1 到 90 秒约 4 级，g2 约 3 级），Sol 的击杀数也从 0 增至约 5–6。英雄缺位使 Luna 更难争夺圣坛或保护部队。
- **约 90–150 秒：Sol 把优势转成规模优势，Luna 未恢复。** 两场中 Sol 都继续训练远程单位、补英雄和研究采集科技；占点时间持续领先。约 120 秒，Sol 人口约 80–91，Luna 约 22。约 150 秒，Sol 人口约 103–116，Luna 仍约 20–22；Sol 的英雄组已扩大并持续升级。Luna 此时仍未见科技升级或英雄复活，累积资源没有转成足够的军力与防守。
- **终局：** g2 在约 173.25 秒、g1 在约 189.75 秒，Sol 部队拆掉 Luna 城镇大厅。终局状态显示 Sol 达到人口上限 120，Luna 在大厅被摧毁前只剩少量人口；Sol 以明显的击杀、伤害和控制时间优势结束比赛。

## 做得较好的地方（Sol）

- 交换座位后仍执行了相近的开局节奏，减少了地图左右侧带来的偶然性解释。
- 开局争取近侧圣坛后，及时把部队分派到中央圣坛；其控制收益与经验优势能从约 24 秒起的占点事件、后续英雄等级和终局控制时间中看到。
- 持续补充靶场、人口容量、英雄和采集研究，把中期优势转化为持续兵力，而非停留在早期小规模交战。
- g1 经济数据中 Sol 的采集量约 9666、控制时间约 565 秒；g2 约 9570、约 564 秒。两场表现相当，表明这套路线在本地图种子下较稳定。

## Luna 的主要失误与可改进方向

1. **开局主力过度集中在中央交战。** 两场早期单位在中央连续阵亡，且没有换来击杀或控制点。可考虑只派足够力量侦察、争夺或牵制，把其余单位分散到可守的占点与经济任务；如果交战不利，应及时撤离而非持续攻击移动。
2. **没有及时处理英雄阵亡。** 死灵法师约一分钟内阵亡后，两场都未再召唤；随后 Sol 英雄升级而 Luna 长时间没有英雄在场。应把英雄生命、撤退距离、复活费用与祭坛队列作为持续决策条件，并在安全时尽早恢复英雄。
3. **经济积累未转化成战力。** 终局 Luna 仍有约 2466–2803 金、920–947 木，但科技仍为一级、采集研究为 0，兵力远低于 Sol。建议明确资源阈值和优先级：先维持农民与人口，再扩建有效生产建筑、补关键科技和单位；避免长期囤积无法改变战局的资源。
4. **缺少中期止损与防守调整。** Sol 在 60–90 秒间已形成持续兵力和英雄优势，Luna 仍未改为守家、集火英雄或分批反击。可用人口差、英雄存活、占点数量作为转守/重组条件，避免以零散部队重复送入优势敌军。

## 结论

两场的胜负脉络一致：Sol 先扩大占点与经济，Luna 的中央早期交战造成兵力损耗；Luna 英雄阵亡后没有恢复，且未把积累资源及时转成科技与生产，Sol 遂滚起人口和英雄等级优势并拆除主基地。最值得优先验证的改进是中央交战止损、英雄复活管理、资源转化节奏和中期防守触发条件。本复盘仅提出建议；没有修改或实现任何策略改进。
