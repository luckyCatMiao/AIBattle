棋谱已由独立窗口枚举程序逐手重建，核对落子合法性、先后手、首次五连、胜者与最终棋盘。源码快照的 SHA-256 校验通过。记录耗时包含进程冷启动及传输开销，不能当作纯计算 CPU 时间。

## 隔离与公平条件

- 两个新 Codex CLI 进程运行于独立挂载和进程命名空间；只提供各自旧源码、自己的历史改进、相同公开棋谱与规则。
- 对方当前源码、对方旧源码、控制器日志、Windows 盘和宿主进程目录未挂载。双向越界读取探针通过；网页也不提供源码或裁判凭据。
- 比赛时策略代码只读、无网络、无认证文件。组织者仅转发局面和提交选手输出，不选择落点。
- 每步目标预算 5 秒，10 秒异常硬上限；双方每轮准备上限相同。原始试赛并未采用完全相同的运行约束，因此不要把两批总比分当成严格同条件对照。
