# 横版羽毛球 · BADMINTON ARENA

侧视 1v1 羽毛球：火柴人隔网对打，可以左右跑、起跳，**上手（从上往下）和下手（从下往上）两种挥拍**。
服务端以 **20 Hz** 固定步长推进，每 **10 帧（0.5 秒）** 双方同时提交一次逐帧输入。

- 游戏服务：<http://127.0.0.1:8808/>（`StartBadminton.bat` / `npm run badminton`）
- 观战回放：<http://127.0.0.1:8809/>（`WatchBadmintonBattle.bat`）

## 比赛

| 项目 | 数值 |
|---|---|
| 球场 | 13.4 格长，中间一张 1.55 格高的网 |
| 比分 | 11 分制，需领先 2 分，15 分封顶 |
| 时长 | 240 秒上限；时间到按比分判定 |
| 发球 | 得分者发球；自动高弧线发球，接发方先回球 |
| 换位 | 系列赛中双方逐局交换座位 |

## 球员

| 参数 | 数值 |
|---|---|
| 身高 / 跑速 | 1.8 格 / **3.7 格·秒⁻¹**（加速 26） |
| 起跳 | 初速 5.3 格·秒⁻¹，约 1.2 格高 |
| 上手挥拍 | 球拍从 2.10 格扫到 1.25 格；第 2–6 帧为击球窗口 |
| 下手挥拍 | 球拍从 0.28 格挑到 1.22 格 |
| 判定半径 | **0.38 格**（只有拍面碰到球才算，体力低时更小） |
| 体力 | 跑动 −9/秒，站定 +6/秒；挥拍 −7，起跳 −10 |
| 蓄力 | 0.77 秒蓄满；移动 ×0.45、每秒 −12 体力；出球速度最高 +55% |
| 冲刺 | 移动 ×1.45、每秒 −26 体力；体力 ≤5 时不可用 |

## 出球规则

上手挥拍的出球由**击球点高度**和**离网距离**共同决定：

- 击球点高、贴近球网 → **杀球**（向下，速度 16–20 格/秒）；
- 在后场 → **高远球**（向上 0.60 弧度，落点靠近对方端线）；
- 对手在后场、自己击球点高 → **吊网前小球**；
- 下压角受网高限制，太靠后会自动改成平高球。

下手挥拍固定是**挑高球**（向上 1.05 弧度，落点靠对方端线）。

球有二次阻力（`a = -k·|v|·v`，k=0.025）和重力；撞网会被挡回，飞出端线判击球方失分，
落在自己半场判对方得分。

## 输入

每次提交 10 帧，每帧一名球员：

```json
{"inputs":[[{"move":0.4,"jump":false,"swing":0}], … 共 10 帧 …]}
```

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `move` | −1 … 1 | 左右跑动 |
| `jump` | 布尔 | 起跳 |
| `swing` | 1 / 0 / −1 | 1 = 上手（从上往下），−1 = 下手（从下往上） |
| `charge` | 布尔 | 蓄力：移动变慢、耗体力，出球更快 |
| `sprint` | 布尔 | 冲刺：移动 ×1.45，持续耗体力 |

- 每帧也接受直接写对象（不包数组）；字段可省略。
- 不足 10 帧的尾部由裁判补中立；字段非法整场判技术负。

## 程序协议

```json
{"mode":"program","command":["python3","agent.py"]}
```

程序持续运行，通过 stdin 每行接收一个 JSON 观察，必须向 stdout 输出**一行** JSON 并立即 flush。
调试日志只写 stderr。单次响应硬上限 **5 秒**。

## 竞技评测

```bash
python badminton/arena/train.py --players deepseek-flash sol --rounds 3 --port 8810 --no-isolation
```

- 每轮 2 局，双方交换座位；3 轮共 6 局。
- 准备阶段默认不设超时；本机直跑模式只把宿主 Claude Code 配置写进临时目录，凭据不进入项目、日志或回放。
- 回放逐物理帧存档（`r*-g*.json.gz`），`arena/audit.js` 会重新执行全部输入并逐帧比对。

## 本地对战

`StartBadminton.bat` / `npm run badminton`：A/D 左右移动，W 起跳，空格上手挥拍，S 下手挥拍。
你控制左侧球员，对手由练习电脑控制；练习电脑按 0.5 秒一个窗口决策，和程序选手一致。
按住 J 蓄力（移动变慢、耗体力，出球速度最高 +55%）；按住 Shift 冲刺（移动 ×1.45，很耗体力）。
判定只看拍面：站到球附近但拍面没对准，就是空挥。
