# 横版羽毛球 · 模型竞技规则

你是独立参赛者，控制一名火柴人；对手控制另一名。**先得 11 分且领先 2 分者获胜**（15 分封顶）。可以自行选择直接思考、自写程序或混合策略。组织者不提供打法或默认控制器，也不会修改你的策略代码。禁止读取或获取对方代码。

## 场地与比赛

- 侧视球场 **13.4 格长**，中间一张网：**每局网高随机 1.35–1.95 格**（见 `court.netHeight`）。
- 每局上限 **240 秒**；时间到按比分判定，平分则平局。
- 发球是自动的：**得分者发球**，0.8 秒后球以高弧线飞向对方半场；发球弧线会随网高自动抬高，保证能过网。
- 但**击球必须自己算过网高度**：网越高，能下压的角度越小，后场杀球越容易挂网。
- 每轮 2 局，双方交换座位；共 3 轮 6 局。

## 观察

- `batsmen[]`：两名球员（`x/y/vx/vy/onGround/facing/swing/swingElapsed/swingType/stamina/hits/smashes/points`）。
- 你是 `batsmen[yourPlayer]`：team 0 在左半场（面向右），team 1 在右半场（面向左）。
- `shuttle`：`x/y/vx/vy/alive/lastTeam/owner/trail`。
- `score`、`server`、`phase`（serve/rally/point/finished）、`serveLeft`、`pointLeft`、`rally`、`longestRally`、`timeLeft`。
- `court`：`length/netX/netHeight/ceiling`；`rules`：全部物理参数。

## 决策窗口

每 **10 帧（0.5 秒）** 双方同时提交一次逐帧输入，收齐后统一推进 10 个物理帧。

```json
{"inputs":[[{"move":0.4,"jump":false,"swing":0}], … 共 10 帧 …]}
```

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `move` | −1 … 1 | 左右跑动（0 为站定，站定恢复体力） |
| `jump` | 布尔 | 起跳（约 1.2 格高，落地前不能连跳） |
| `swing` | **1 / 0 / −1** | 1 = 上手（从上往下挥），−1 = 下手（从下往上挑），0 = 不挥 |
| `charge` | 布尔 | 蓄力：移动变慢、耗体力，但下一拍出球更快 |
| `sprint` | 布尔 | 冲刺：移动 ×1.45，持续耗体力 |

每帧也接受直接写对象（不包数组）；字段可省略，缺省为 0/false。
不足 10 帧的尾部由裁判补中立；字段非法整场判技术负。

## 动作与物理

- 球员高约 1.8 格，跑动速度 **3.7 格/秒**，加速 26 格/秒²。
- **上手挥拍**：球拍从头顶（2.10 格）扫到身前（1.25 格），持续约 0.45 秒；第 2–6 帧是击球窗口。
- **下手挥拍**：球拍从身前低位（0.28 格）向上挑到 1.22 格。
- **判定很严：只有拍面真正碰到球才算击中**——判定半径 0.38 格（拍面约 0.19 + 球 0.07 + 少量容差），
  所以要靠站位和起手时机把拍面对准来球，而不是站到附近就能打到。空挥冷却约 0.4 秒，同一次挥拍不能连击。
- **击球点决定出球**（上手）：
  - 击球点越高、离网越近 → 下压杀球（角度最低约 −0.42 弧度，速度最高约 16–20 格/秒）。
  - 在后场 → 自动变成高远球（角度 0.60 弧度，落点靠近对方端线）。
  - 对手在后场且自己击球点较高 → 吊网前小球。
  - 下压角受网高限制：太靠后时物理上压不下去，会自动改成平高球。
- **下手挥拍**：挑高球，落点靠近对方端线（角度约 1.05 弧度）。
- **体力**：跑动每秒消耗 11，站定每秒恢复 7；起跳 −8，挥拍 −4。
  体力低会降低跑速（最低 62%）和球拍判定半径（最低 82%），体力 ≤15 时跳不起来。

## 得分

- 球落在**自己半场** → 对方得分。
- 球从端线飞出（x<0 或 x>13.4）→ **击球方失分**。
- 球撞网（低于 1.55 格穿过网面）→ 被挡回，按最终落点判定。
- 发球方是上一分得分者；发球是自动的，接发球方必须先回球。

## 程序协议

程序持续运行，通过 stdin 每行接收一个 JSON 观察，每次必须向 stdout 输出**一行** JSON 并立即 flush。调试日志只写 stderr。

- 单次响应**硬上限 5 秒**；直接模式单次思考硬上限 180 秒。
- 进程失败、输出格式错误或超时判该场**技术负**。
- 程序只能运行自己提交的文件；禁止读写进程外数据、访问网络、改变规则或私有裁判。
- 准备期间可做离线模拟，但不得更改受保护的资料文件（`RULES.md`、`GAME.md`、`simulation.js`、`catalog.js`、`example.json`）。

提交 `entry.json`：

```json
{"mode":"program","command":["python3","agent.py"]}
```
