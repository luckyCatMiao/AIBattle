# 3V3 足球 · SOCCER ARENA

每队 1–6 名球员（每局按种子随机，双方相同）的俯视足球，1v1 solo 也可能。球是实体，有速度、摩擦和墙面反弹；没有战争迷雾。
服务端以 **20 Hz** 固定步长推进，每 **20 帧（1 秒）** 双方同时提交一次逐帧输入。

- 游戏服务：<http://127.0.0.1:8801/>（`StartSoccer.bat` / `npm run soccer`）
- 观战回放：<http://127.0.0.1:8802/>（`WatchSoccerBattle.bat`）

## 比赛

| 项目 | 数值 |
|---|---|
| 球场 | 44×26 格，四周有墙；左右各一个 6 格宽球门 |
| 人数 | 每队 1–6 人（每局按种子随机，双方相同） |
| 时长 | 120 秒（60 秒下半场） |
| 平局 | 20 秒金球；金球进球立即结束，仍平则平局 |
| 进球后 | 中圈重新开球，冻结 0.6 秒 |
| 换边 | 不换边；系列赛中双方逐局交换座位 |

## 球员与球

- 球员半径 0.34 格，无球移动速度 3.15 格/秒；**持球时降速到 58%**（约 1.83 格/秒）。
- 球半径 0.22 格；踢出速度约 **11 格/秒**，每物理帧乘 0.978；撞墙反弹 0.72。
- 球员进入球 0.82 格内自动控球；控球时球贴在朝向前方 0.62 格。
- 对手更近地逼近球（近 0.12 格以上）会抢断；刚被抢断的一方 0.18 秒内不能反抢。
- 踢球冷却 0.35 秒；踢出后 0.3 秒内不能重新控球。
- 球心越过球门线（x ≤ 1 或 x ≥ 43）且在 y=10..16 内即进球；乌龙球记给对方。

### 禁区与守门员

- 禁区 9 格深、14 格高。**任何单位进入对方禁区都犯规**；防守方可以在本方禁区防守。
- 犯规：球放在禁区外最近的任意球点，暂停 0.6 秒；犯规者移出并僵直 1 秒，由被犯规方开球。
- 每队 `index 0` 是守门员。守门员在本方禁区内有 **1.35 格**扑救半径：
  球速 ≥4.5 格/秒时可直接没收射门。离开本方禁区没有加成。

## 输入

每次提交 20 帧，每帧 `teamSize` 个单位的输入（人数每局随机，以观察里的 `teamSize` 为准；下面示例为 3 人局）：

```json
{"inputs":[[
  {"dir":"R","aim":0,"kick":false},
  {"dir":"N","aim":90,"kick":false},
  {"dir":"UL","aim":null,"kick":false}
], … 共 20 帧 …]}
```

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `dir` | `N` / `U` / `D` / `L` / `R` / `UL` / `UR` / `DL` / `DR` | 八方向移动 |
| `aim` | 八方向名，或 0–359 的角度（度） | 朝向；0=右，90=下，180=左，270=上。省略或 `N` 时朝向跟随移动 |
| `kick` | 布尔 | 沿当前朝向踢球 |

- 不足 20 帧的尾部由裁判补中立；方向名/字段非法、超过 20 帧整场判技术负。
- `aim` 用数值角度可以精确射门/传球；只用八方向会损失精度。

## 程序协议

```json
{"mode":"program","command":["python3","agent.py"]}
```

程序持续运行，通过 stdin 每行接收一个 JSON 观察，必须向 stdout 输出**一行** JSON 并立即 flush。
调试日志只写 stderr。单次响应硬上限 **5 秒**。

## 竞技评测

```bash
python soccer/arena/train.py --players deepseek-flash sol --rounds 3 --port 8803
```

- 每轮 2 局，双方交换座位；3 轮共 6 局。
- 准备阶段默认不设超时；每名选手的凭据写入 WSL 私有 home，不进入项目、日志或回放。
- 比赛执行时工作区只读且无网络；受保护的规则/引擎文件做哈希校验。
- 回放逐物理帧存档（`r*-g*.json.gz`），`arena/audit.js` 会重新执行全部输入并逐帧比对。

## 本地对战

`StartSoccer.bat` / `npm run soccer`，WASD 移动，鼠标瞄准，空格踢球；你控制 1 号球员，
其余队友和对手由练习电脑控制。
