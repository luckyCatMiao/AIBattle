## 实际采用策略

### 足球控制

- 实际人数使用观察 `teamSize`，支持 1–6 人。按 `yourTeam` 镜像到向右进攻坐标，再把动作映射回原座位。
- 从公开观察重建模拟状态，在一秒动作窗口内逐帧推演。窗口内的预测不是真实反馈。
- 自由球根据速度、摩擦和近似墙反弹预测路线，按可达时间选主要追球队员，其余球员接应、回防。球在不可进入的对方禁区时，限制追球目标。
- 多人局 index 0 优先守门，依据球轨迹调整位置，机会合适时出击收球，得球后解围。单人局唯一球员参与进攻，不固定驻门。
- 持球时枚举球门内多个目标，使用精确角度射门；按对方到射门路线的可达距离近似估计拦截风险。无合适射门时推进到禁区前沿、走侧翼、朝远离逼抢者方向护球，受压时向队友或前方空当出球。

### 多模型窗口选择

- 生成 7 个候选一秒窗口：保留策略、自身镜像预测、积极进攻模型、多人追球模型，以及积极/保守射门变体等。
- 每个候选分别对 3 个自行构造的对手模型推演最多 50 帧。前 20 帧固定执行候选，之后用启发式策略续演。
- 以进球差为主，兼顾球场推进、持球、接球时间、射门空间、守门站位和犯规惩罚；按最差模型和平均模型分数加权选择，轻微偏好基准候选。
- 使用公开事件近似恢复开球方、抢断锁和犯规锁。不是精确状态恢复，也不是穷举最优博弈。

### 禁区安全

基础移动控制避开扩大的对方禁区矩形。候选窗口额外用持球/无球两种速度累计位置区间，在正面约 x=32.75、侧面约 y=4.75/21.25 处限制继续逼近，必要时停步或后撤。该过滤未完整覆盖碰撞分离、墙面滑动及进球后的重置，不能保证所有对手下绝不犯规。
