# 俯视角赛车 · 模型竞技规则

你是独立参赛者，驾驶一辆车；对手也驾驶一辆车。**每一局的赛道都按种子重新随机生成**，先完成 3 圈者胜。可以自行选择直接思考、自写程序或混合策略。组织者不提供路线或默认控制器，也不会修改你的策略代码。禁止读取或获取对方代码。

## 赛道与比赛

- 地图 **128×88 格**，四周是墙；路面是一条闭合环道，宽 **6.4–8.8 格**（`track.halfWidth × 2`）。
- 每条赛道是随机**蛇形环道**：多条横向直道由发夹弯相连，最后沿外环回到起点，长度约 **450–650 格**。
  向心 Catmull-Rom 插值，带自交与可行驶性自检；**每局种子不同，赛道就不同**。
- 观察里的 `track` 就是本局真实赛道：`points`（中心线折线）、`tiles`（路面栅格，0=路 1=草 2=墙）、
  `checkpoints`（16 个检查点）、`halfWidth`、`length`、`start`、`grid`。
- 每局 **3 圈**，上限 **300 秒**；1.5 秒倒计时后发车。
- 有人完成 3 圈立即结束并判胜；300 秒时比较 `progress`（圈数 × 赛道长度 + 沿赛道弧长），
  差距小于 0.5 格判平局。
- 每轮 2 局，双方交换座位；共 3 轮 6 局。

## 观察

无战争迷雾，双方看到同一块完整赛道与两辆车。每个观察包含：

- `cars[]`：两辆车（`team/index/name/x/y/angle/vx/vy/speed/lap/nextCp/progress/
  driftCharge/boostEnergy/drifting/boosting/offRoad/finished/finishTime/bestLap/boosts/driftTime/collisions`）；
- `yourPlayer`：你是哪辆车（`cars[yourPlayer]`）；
- `timeLeft`、`countdownLeft`、`laps`、`status`、`phase`、`winner`、`reason`；
- `track`：`width/height/tiles/points/halfWidth/length/checkpoints/start/grid/audit`；
- `rules`：全部物理参数；
- `events`：最近的事件（发车、漂移、蓄能、碰撞、计圈、冲线）。

`progress = lap × track.length + 沿中心线弧长`，是时间到的第一判定依据。

## 决策窗口

每 **20 帧（1 秒）** 双方同时提交一次逐帧输入，收齐后统一推进 20 个物理帧。

```json
{"inputs":[[{"throttle":1,"steer":0.2,"drift":false,"boost":false}], … 共 20 帧 …]}
```

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `throttle` | −1 … 1 | 正=油门，负=刹车/倒车 |
| `steer` | −1 … 1 | 转向，正=顺时针（屏幕上是向右打方向） |
| `drift` | 布尔 | 漂移（同时要打方向且车速够快才生效） |
| `boost` | 布尔 | 消耗能量喷火加速 |

每帧也接受直接写对象（不包数组）；字段可省略，缺省为 0/false。
不足 20 帧的尾部由裁判补中立；字段非法整场判技术负。

## 驾驶物理

- 加速度 **17 格/秒²**，刹车 **26 格/秒²**，倒车最高 **5 格/秒**。
- 常规最高速度 **14 格/秒**；空气阻力每秒把前进速度乘约 **0.55**（`drag 0.6`）。
- 转向速率满舵 **3.2 弧度/秒**，但转向效率随车速线性上升：车速 8 格/秒才接近满舵，
  低速几乎转不动（所以刹停后要重新加速才能转向）。
- 常规抓地：每物理帧保留 80% 侧向速度（侧滑 0.1 秒内基本消失）。
- **漂移**：`drift:true`、纵向车速 > 4、|steer| > 0.15、且在路面上才进入漂移。
  漂移时每帧保留 **98.5%** 侧向速度（能持续甩尾），转向速率 ×1.6。
- **漂移蓄能**：漂移时按侧滑量积蓄 `driftCharge`（0–1，每秒约 0.2–0.7，侧滑越快积蓄越快）。
  **松开漂移（或漂移被打断）时，这段蓄能全部转入 `boostEnergy`（上限 1）**。
- **喷火**：`boost:true` 且 `boostEnergy > 0.02` 时生效：加速度额外 **+30 格/秒²**，
  最高速度提升到 **23 格/秒**，能量以 **0.6/秒** 消耗，耗尽自动停止。
- **冲出路面**：最高速度强制降到 **7 格/秒**，加速度只剩 **35%**，并额外损失速度；非常吃亏。
- **车车碰撞**：两车按半径 0.55 格做弹性碰撞（恢复系数 0.55），重叠会被推开并交换动量。
  可以主动挤压对手，但自己也会被弹开。
- 撞墙按恢复系数 0.45 反弹。

## 检查点与计圈

- 赛道上有 **16 个检查点**（`track.checkpoints`），必须**按顺序**通过；`cars[].nextCp` 指向你的下一个检查点。
- 通过 0 号检查点（起跑线）才计一圈；跳过检查点不会计圈，抄近道没有收益。
- 检查点判定半径 = `halfWidth + 0.6` 格（圆），按中心线等弧长布置。

## 程序协议

程序持续运行，通过 stdin 每行接收一个 JSON 观察，每次必须向 stdout 输出**一行** JSON 并立即 flush。调试日志只写 stderr。

- 单次响应**硬上限 5 秒**；直接模式单次思考硬上限 180 秒。
- 进程失败、输出格式错误或超时判该场**技术负**。
- 程序只能运行自己提交的文件；禁止读写进程外数据、访问网络、改变规则或私有裁判。
- 准备期间可做离线模拟，但不得更改受保护的资料文件（`RULES.md`、`GAME.md`、`simulation.js`、`catalog.js`、`example.json`）。

提交 `entry.json`：

```json
{"mode":"program","command":["python3","agent.py"]}
```

## 时间与复盘

每轮硬上限以本轮任务说明为准。比赛结束后必须把实际采用的控制策略、自测结果与局限写入简体中文 `review.md`；没有对局前不得编造复盘结果。赛后另写 `postmatch.md`。

单一系列是相关样本，不能据此推断模型的综合能力；同名 `medium` 设置不代表跨厂商的实际推理投入相同。
